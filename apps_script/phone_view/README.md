# หน้ามือถือคนถ่ายรูป (ตั้งแต่ 5.5.85 • หน้าตาใหม่ 5.5.88)

หน้าเว็บสำหรับคนถ่ายรูปเปิดในมือถือ เห็นว่าถ่ายไปแล้วกี่ % และหนังเรื่องไหนยังไม่ได้ถ่าย ทีละจอ — ไม่ต้องเปิดไฟล์ Excel

- **PHOTO CHECK STUDIO** ส่งข้อมูลมาให้ (หน้างานโฟลเดอร์และรูป → **ขั้นที่ 4 ส่งเข้าหน้ามือถือ** — คัดรูปและใส่วันที่ถ่ายเสร็จแล้วค่อยส่ง)
  - ส่งเฉพาะรายชื่อหนังต่อจอ (รหัส • TYPE • ชื่อจอ): ถ่ายแล้ว (วันที่ถ่าย) / ยังไม่ถ่าย / วันที่หนังออก — **ไม่ส่งไฟล์ใบเช็ค**
- **คนถ่ายรูป** เปิดลิงก์เดียวกันในมือถือ (เข้าด้วยอีเมลบริษัท ดูได้อย่างเดียว) — **เห็นเฉพาะใบเช็คของตัวเอง**
- **คนคัดรูป** เห็นและส่งข้อมูลได้เฉพาะใบเช็คที่มีอีเมลตัวเอง • **หัวหน้า** เห็นทุกใบ ส่งได้ทุกใบ — ตั้งในแท็บ **ผู้ใช้และสิทธิ์**
- ทำงานในบัญชี Google ของบริษัทเอง (ฟรี ไม่ต้องติดตั้งโปรแกรม) • ไม่ได้ใช้ AI ตอนทำงาน — เป็นสคริปต์ธรรมดา

ไฟล์: `Code.gs` (สคริปต์ + หน้ารับข้อมูลจาก PHOTO CHECK STUDIO) • `Phone.html` (หน้ามือถือ)

## ติดตั้งครั้งแรก (ประมาณ 10 นาที ทำครั้งเดียว)

ใช้บัญชี Google ของบริษัท

1. เปิด Google Drive → **ใหม่ → Google ชีต** ตั้งชื่อ `หน้ามือถือคนถ่ายรูป`
2. ในชีต เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจากไฟล์ `Code.gs` นี้
4. กด **＋ (เพิ่มไฟล์) → HTML** ตั้งชื่อว่า `Phone` (ไม่ต้องพิมพ์ .html) ลบของเดิม แล้ววางโค้ดจากไฟล์ `Phone.html`
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)
6. กลับไปที่ชีต กด **รีเฟรช** → จะมีเมนู **หน้ามือถือ** ด้านบน → กด **หน้ามือถือ → ตั้งค่าครั้งแรก**
   - ครั้งแรก Google ถามสิทธิ์ → **ตรวจสอบสิทธิ์** → เลือกบัญชี → ถ้าขึ้นว่า “Google ยังไม่ได้ยืนยันแอปนี้” กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต**
     (เป็นสคริปต์ที่คุณสร้างเองในบัญชีตัวเอง ข้อความนี้ขึ้นกับสคริปต์ส่วนตัวทุกตัว)
   - ได้แท็บ **ผู้ใช้และสิทธิ์** และโฟลเดอร์ `หน้ามือถือคนถ่ายรูป (ข้อมูล)` ใน Drive
7. **เผยแพร่หน้ามือถือ**: ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ไอคอนฟันเฟือง → เลือก **เว็บแอป**
   - **เรียกใช้ในฐานะ: ฉัน** • **ผู้มีสิทธิ์เข้าถึง: ทุกคนในองค์กร (planbmedia.co.th)**
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ขึ้นต้น `https://script.google.com/` ลงท้าย `/exec`)
   - ดูลิงก์ทีหลังได้จากเมนู **หน้ามือถือ → ลิงก์หน้ามือถือ**
8. ใน PHOTO CHECK STUDIO เปิดหน้า **งานโฟลเดอร์และรูป** → **ขั้นที่ 4 ส่งเข้าหน้ามือถือ**
   → วางลิงก์ → **บันทึกลิงก์** (ระบบจำไว้ ทำครั้งเดียว) → กด **ส่งเข้าหน้ามือถือ**

## ส่งข้อมูลจาก PHOTO CHECK STUDIO (หลังคัดรูปและใส่วันที่ถ่าย)

- หน้า **งานโฟลเดอร์และรูป** → ขั้นที่ 3 **ใส่วันที่ถ่าย** → กด **ไปขั้นที่ 4 ส่งเข้าหน้ามือถือ** → กด **ส่งเข้าหน้ามือถือ** → หน้าต่างเล็กเปิดขึ้น รับข้อมูล บันทึก แล้วปิดเอง
- ส่งใบเช็คชุดที่ใช้ในหน้านั้น (หลังใส่วันที่ถ่ายเป็นฉบับที่ใส่แล้ว) • ส่งซ้ำได้ ข้อมูลใหม่แทนของเดิมของใบนั้น
- คนถ่ายรูปเปิดลิงก์เดิมเห็นข้อมูลใหม่ทันที (มุมบนบอก “ข้อมูลวันที่ … เวลา …”)
- **ใครส่งได้**: เจ้าของชีต และหัวหน้า (แถว 2) = ทุกใบ • คนคัดรูป (คอลัมน์ C) = เฉพาะใบที่มีอีเมลตัวเอง — ใบอื่นในชุดถูกข้าม (หน้าต่างบอกว่าข้ามใบไหน)
- ใบเช็คชื่อใหม่ (ยังไม่มีในแท็บ) หัวหน้าเป็นคนส่งครั้งแรก ชื่อจึงขึ้นในแท็บ
- ครั้งแรกถ้า Chrome กันหน้าต่างเด้ง กดอนุญาตป๊อปอัปของหน้า PHOTO CHECK STUDIO • ถ้าหน้าต่างขึ้นหน้าล็อกอิน ให้ล็อกอินอีเมลบริษัทแล้วกดส่งอีกครั้ง

## ใครเห็นอะไร (แท็บ ผู้ใช้และสิทธิ์)

| ใคร | ใส่อีเมลที่ | เห็นในหน้ามือถือ | ส่งข้อมูล |
|---|---|---|---|
| หัวหน้า | แถว 2 (ช่องสีเหลือง) | ทุกใบ (เลือกชื่อด้านบน) | ได้ทุกใบ |
| คนคัดรูป | คอลัมน์ C ของใบนั้น | เฉพาะใบที่มีอีเมลตัวเอง | ได้เฉพาะใบเหล่านั้น |
| คนถ่ายรูป | คอลัมน์ B ของใบนั้น | เฉพาะใบของตัวเอง | ไม่ได้ (ดูอย่างเดียว) |

- หลายคนในช่องเดียวคั่นด้วย `,` • เจ้าของชีตเห็นทุกใบเสมอ • แก้แท็บแล้วมีผลทันที
- คนที่ไม่มีอีเมลในแท็บ เปิดลิงก์แล้วเห็นข้อความว่า “ยังไม่มีใบเช็คที่เปิดดูได้” พร้อมอีเมลของเขา (ส่งมาให้หัวหน้าใส่ได้เลย)
- คอลัมน์ ส่งล่าสุด / จอ / ถ่ายแล้ว ระบบเขียนให้ทุกครั้งที่ส่ง (ไม่ต้องแก้) • อย่าเปลี่ยนชื่อแท็บ และอย่าลบแถว 1–5

## ส่งลิงก์ให้คนถ่ายรูป

- เมนู **หน้ามือถือ → ลิงก์หน้ามือถือ** → คัดลอกลิงก์ที่ลงท้ายด้วย `?openExternalBrowser=1` → ส่งใน LINE
  - LINE จะเปิดใน Chrome ซึ่งจำการล็อกอิน Google ไว้ (ในเบราว์เซอร์ของ LINE มักต้องล็อกอินใหม่ทุกครั้ง หรือล็อกอินไม่ได้)
  - ใน Chrome กด ⋮ → **เพิ่มลงในหน้าจอหลัก** ได้ไอคอนไว้กดเปิดครั้งต่อไป
- เปิดครั้งแรก Google ให้ล็อกอินอีเมลบริษัท (ถ้ามือถือล็อกอินอยู่แล้วก็เข้าได้เลย)
- ทุกคนใช้ลิงก์เดียวกัน แต่ละคนเห็นเฉพาะของตัวเอง

## หน้ามือถือแสดงอะไร (แบบใหม่ 5.5.88)

- **หน้าแรก**: แถบหัวสีน้ำเงิน (สีเดียวกับใบเช็ค) ชื่อใบเช็ค • วงกลม % ที่ถ่ายแล้ว • ยังไม่ถ่าย / ถ่ายแล้ว / จำนวนจอ • รายชื่อจอ (ถ่ายน้อยอยู่บน จอที่ครบขึ้น “ครบ”)
  - แต่ละจอ: **รหัสจอ** (พื้นฟ้าแบบแถบรหัสในใบเช็ค) • **TYPE จอ** เช่น 4-3, 16-9, AT16-9 • **ชื่อจอ** • แพ็กเกจ — อ่านจากแถวใต้รหัสจอในใบเช็ค (จอ BKJ / Metro ในใบเช็คไม่มี TYPE)
- **กดที่จอ**: 3 แถบ
  - **ยังไม่ถ่าย** — หนังที่ใกล้ออกอยู่บน: ป้าย **ออกวันนี้** / **ออกพรุ่งนี้** (มีจุดแดง) / **ออก 2 ธ.ค.**
  - **ถ่ายแล้ว** — บอกวันที่ถ่ายจากช่องในใบเช็ค
  - **ออกแล้ว** — หนังที่วันที่ออกผ่านไปแล้ว บอกว่า **ถ่ายทัน** (วันที่ถ่าย) หรือ **ไม่ได้ถ่าย** • ออกล่าสุดอยู่บน
  - ช่องค้นหาชื่อหนัง
- **% และจำนวนค้าง นับเฉพาะหนังที่ยังฉายอยู่** (ไม่นับหนังที่ออกไปแล้ว) จึงอาจต่างจากคะแนนในใบเช็ค — หน้าแรกบอกจำนวนหนังที่ออกไปแล้ว
- **โหมดกลางแดด**: ปุ่มรูปพระอาทิตย์มุมขวาบน — พื้นขาวล้วน ตัวดำ ตัวใหญ่ขึ้น เส้นเข้ม • มือถือจำไว้ • มือถือที่ตั้งโหมดมืด หน้านี้เป็นโหมดมืดให้เอง
- ต้องมีเน็ตตอนเปิด • เปิดขึ้นมาแล้ว กดดูจอ สลับแถบ และค้นหา ไม่ต้องใช้เน็ต

## ข้อมูลเก็บที่ไหน

- โฟลเดอร์ `หน้ามือถือคนถ่ายรูป (ข้อมูล)` ใน Drive ของเจ้าของชีต — ไฟล์ `.json` 1 ไฟล์ต่อใบเช็ค (ส่งใหม่เขียนทับ) **อย่าลบหรือย้ายไฟล์**
- คนถ่ายรูปไม่ได้สิทธิ์ชีตหรือโฟลเดอร์ — เห็นได้เฉพาะผ่านหน้ามือถือ

## แก้โค้ดภายหลัง

วางโค้ดใหม่ใน `Code.gs` / `Phone` → บันทึก → **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (ลิงก์เดิมใช้ต่อได้)
