# หน้ามือถือคนถ่ายรูป (ตั้งแต่ 5.5.85)

หน้าเว็บสำหรับคนถ่ายรูปเปิดในมือถือ เห็นว่าถ่ายไปแล้วกี่ % และหนังเรื่องไหนยังไม่ได้ถ่าย ทีละจอ — ไม่ต้องเปิดไฟล์ Excel

- **PHOTO CHECK STUDIO** ส่งข้อมูลมาให้หลังเติมใบเช็ค (หน้าผลการเติม → ปุ่ม **ส่งเข้าหน้ามือถือ**)
  - ส่งเฉพาะรายชื่อหนังต่อจอ: ถ่ายแล้ว (วันที่ถ่าย) / ยังไม่ถ่าย (วันที่หนังออก) — **ไม่ส่งไฟล์ใบเช็ค**
- **คนถ่ายรูป** เปิดลิงก์เดียวกันในมือถือ (เข้าด้วยอีเมลบริษัท ดูได้อย่างเดียว) — **แต่ละคนเห็นเฉพาะใบเช็คของตัวเอง**
- **ผู้ดูแล / หัวหน้า** เห็นทุกคน (เลือกชื่อด้านบน) และกำหนดว่าใครเห็นใบไหนในแท็บ **ผู้ใช้และสิทธิ์**
- ทำงานในบัญชี Google ของบริษัทเอง (ฟรี ไม่ต้องติดตั้งโปรแกรม) • ไม่ได้ใช้ AI ตอนทำงาน — เป็นสคริปต์ธรรมดา

ไฟล์: `Code.gs` (สคริปต์ + หน้ารับข้อมูลจาก PHOTO CHECK STUDIO) • `Phone.html` (หน้ามือถือ)

## ติดตั้งครั้งแรก (ประมาณ 10 นาที ทำครั้งเดียว)

ใช้บัญชี Google ของบริษัท

1. เปิด Google Drive → **ใหม่ → Google ชีต** ตั้งชื่อ `หน้ามือถือคนถ่ายรูป`
2. ในชีต เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจากไฟล์ `Code.gs` นี้
4. กด **＋ (เพิ่มไฟล์) → HTML** ตั้งชื่อว่า `Phone` (ไม่ต้องพิมพ์ .html) ลบของเดิม แล้ววางโค้ดจากไฟล์ `Phone.html`
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)
6. กลับไปที่ชีต กด **รีเฟรช** → จะมีเมนู **หน้ามือถือ** ด้านบน → กด **หน้ามือถือ → ตั้งค่าครั้งแรก**
   - ครั้งแรก Google ถามสิทธิ์ → **ตรวจสอบสิทธิ์** → เลือกบัญชี → ถ้าขึ้นว่า “Google ยังไม่ได้ยืนยันแอปนี้” กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต**
     (เป็นสคริปต์ที่คุณสร้างเองในบัญชีตัวเอง ข้อความนี้ขึ้นกับสคริปต์ส่วนตัวทุกตัว)
   - ได้แท็บ **ผู้ใช้และสิทธิ์** และโฟลเดอร์ `หน้ามือถือคนถ่ายรูป (ข้อมูล)` ใน Drive
7. **เผยแพร่หน้ามือถือ**: ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ไอคอนฟันเฟือง → เลือก **เว็บแอป**
   - **เรียกใช้ในฐานะ: ฉัน** • **ผู้มีสิทธิ์เข้าถึง: ทุกคนในองค์กร (planbmedia.co.th)**
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ขึ้นต้น `https://script.google.com/` ลงท้าย `/exec`)
   - ดูลิงก์ทีหลังได้จากเมนู **หน้ามือถือ → ลิงก์หน้ามือถือ**
8. ใน PHOTO CHECK STUDIO เติมใบเช็คตามปกติ → หน้าผลการเติม กล่อง **ทำต่อ** → **ส่งเข้าหน้ามือถือคนถ่ายรูป**
   → วางลิงก์ → **บันทึกลิงก์** (ระบบจำไว้ ทำครั้งเดียว) → กด **ส่งเข้าหน้ามือถือ**

## ส่งข้อมูลจาก PHOTO CHECK STUDIO (ทุกครั้งหลังเติม)

- หน้าผลการเติม กล่อง **ทำต่อ** → กด **ส่งเข้าหน้ามือถือ** → หน้าต่างเล็กเปิดขึ้น รับข้อมูล บันทึก แล้วปิดเอง
- ส่งทุกไฟล์ที่เติมได้ในรอบนั้น • ส่งซ้ำได้ ข้อมูลใหม่แทนของเดิมของคนนั้น
- คนถ่ายรูปเปิดลิงก์เดิมเห็นข้อมูลใหม่ทันที (มุมบนบอก “ข้อมูลวันที่ … เวลา …”)
- ส่งได้เฉพาะเจ้าของชีต และอีเมลในช่อง **ผู้ดูแล / หัวหน้า** ของแท็บผู้ใช้และสิทธิ์
- ครั้งแรกถ้า Chrome กันหน้าต่างเด้ง กดอนุญาตป๊อปอัปของหน้า PHOTO CHECK STUDIO
- ถ้าหน้าต่างขึ้นหน้าล็อกอิน ให้ล็อกอินอีเมลบริษัทแล้วกดส่งอีกครั้ง

## ใครเห็นอะไร (แท็บ ผู้ใช้และสิทธิ์)

- ส่งข้อมูลครั้งแรกแล้ว ชื่อใบเช็คขึ้นในคอลัมน์ **ใบเช็ค** เอง (ชื่อไฟล์ใบเช็ค เช่น `คุณ_A.xlsm` → `คุณ_A`)
- พิมพ์อีเมลบริษัทของคนถ่ายรูปในช่อง**สีเหลือง**ข้างชื่อใบเช็ค (หลายคนคั่นด้วย `,`)
- ช่อง **ผู้ดูแล / หัวหน้า** (แถว 2) — อีเมลที่เห็นทุกคน และส่งข้อมูลจาก PHOTO CHECK STUDIO ได้ • เจ้าของชีตเห็นทุกคนเสมอ
- คนที่ไม่มีอีเมลในแท็บ เปิดลิงก์แล้วเห็นข้อความว่า “ยังไม่มีใบเช็คที่เปิดดูได้” พร้อมอีเมลของเขา (ส่งมาให้ผู้ดูแลใส่ได้เลย)
- แก้แท็บแล้วมีผลทันที
- คอลัมน์ ส่งล่าสุด / จอ / ถ่ายแล้ว ระบบเขียนให้ทุกครั้งที่ส่ง (ไม่ต้องแก้)
- อย่าเปลี่ยนชื่อแท็บ และอย่าลบแถว 1–5

## ส่งลิงก์ให้คนถ่ายรูป

- เมนู **หน้ามือถือ → ลิงก์หน้ามือถือ** → คัดลอก → ส่งใน LINE
- เปิดครั้งแรก Google ให้ล็อกอินอีเมลบริษัท (ถ้ามือถือล็อกอินอยู่แล้วก็เข้าได้เลย)
- ทุกคนใช้ลิงก์เดียวกัน แต่ละคนเห็นเฉพาะของตัวเอง

## หน้ามือถือแสดงอะไร

- **หน้าแรก**: ชื่อใบเช็ค • วงกลม % ที่ถ่ายแล้ว • ถ่ายแล้ว / ยังไม่ถ่าย / จำนวนจอ • รายชื่อจอ บรรทัดละจอ บอกว่าค้างกี่เรื่อง (จอที่ถ่ายน้อยอยู่บนสุด จอที่ครบแล้วขึ้น “ครบ”)
- **กดที่จอ**: รหัสจอ แพ็กเกจ สถานที่ • ถ่ายแล้วกี่เรื่องจากกี่เรื่อง • ปุ่มสลับ **ยังไม่ถ่าย / ถ่ายแล้ว** • ช่องค้นหาชื่อหนัง
  - ยังไม่ถ่าย: ป้ายแดง **ออก 2 ธ.ค.** = วันที่หนังออก (ถ่ายก่อนวันนี้) • ป้ายเทา **ออกแล้ว 13 พ.ย.** = ออกไปแล้ว ถ่ายไม่ได้แล้ว (อยู่ท้ายรายการ)
  - ถ่ายแล้ว: บอกวันที่ถ่ายจากช่องในใบเช็ค
- ตัวเลขนับแบบเดียวกับสูตรในใบเช็ค (จำนวนสินค้า = ชื่อหนังตั้งแต่แถว 21 • ถ่ายแล้ว = ช่องจอที่มีตัวเลขวันที่ถ่าย)
- บล็อกที่หลายจอใช้รายชื่อหนังเดียวกัน (BKJ / Metro / MRT) แยกเป็นจอละรายการ
- ใช้ได้ทั้งโหมดสว่างและโหมดมืดของมือถือ

## ข้อมูลเก็บที่ไหน

- โฟลเดอร์ `หน้ามือถือคนถ่ายรูป (ข้อมูล)` ใน Drive ของเจ้าของชีต — ไฟล์ `.json` 1 ไฟล์ต่อใบเช็ค (ส่งใหม่เขียนทับ) **อย่าลบหรือย้ายไฟล์**
- คนถ่ายรูปไม่ได้สิทธิ์ชีตหรือโฟลเดอร์ — เห็นได้เฉพาะผ่านหน้ามือถือ

## แก้โค้ดภายหลัง

วางโค้ดใหม่ใน `Code.gs` / `Phone` → บันทึก → **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (ลิงก์เดิมใช้ต่อได้)
