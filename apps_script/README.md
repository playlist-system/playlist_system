# ดึง Playlist อัตโนมัติด้วย Google Apps Script

สคริปต์ `Code.gs` ทำงานในบัญชี Google ของคุณเอง ไม่มีค่าใช้จ่าย ไม่ต้องติดตั้งโปรแกรม และไฟล์ไม่ผ่านบริการภายนอก

- **ทุกชั่วโมง 7:00–18:00** (เวลาไทย) ค้น Gmail หาอีเมลที่แนบไฟล์ Excel
- เก็บ Playlist **ของวันนี้** ลง Google Drive ในโฟลเดอร์ `Playlist รายวัน/Playlist_ปปปป-ดด-วว`
  - **Playlist ที่ต้องใช้ 10 แบบ** (นับว่าครบ 10/10): สรุปรายการหนังแยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Show DC • Signature Max • BKJ1 • BKJ2
  - **Playlist เพิ่มเติม** ถ้ามีมาทางอีเมล (ไม่นับใน 10 แบบ): Rama9 Connect, Digital MRT, Gateway X, Air Traveller, The 20, LA PlanB
  - **Show DC และ LA PlanB** ไม่ได้ส่งทุกวัน ถ้าวันนี้ยังไม่มีฉบับใหม่ ใช้ฉบับล่าสุดไปก่อน (ค้นย้อนหลัง 14 วัน) พอฉบับของวันนี้มา ฉบับเก่าย้ายไปถังขยะของ Drive ให้เอง
  - วันที่ของไฟล์ดูจากชื่อไฟล์ เหมือน PHOTO CHECK STUDIO เช่น `2026 10 20`, `20-10-26`, `2026_Oct_20`, `20 Oct 26`, `20261020` ถ้าชื่อไม่มีวันที่ ใช้วันที่ของอีเมล
  - ไฟล์เดิมไม่เก็บซ้ำ ไฟล์ชื่อเดิมแต่ขนาดต่าง (ฉบับแก้) เก็บเพิ่มและเตือนในอีเมล
- **ส่งอีเมลสรุป** ทุกครั้งที่มีไฟล์ใหม่ เช่น “Playlist 20 ต.ค. 2569: 10/10 แบบ — ครบแล้ว” บอกว่าขาดแบบไหน มีลิงก์เปิดโฟลเดอร์
- **Metro LED มาทาง LINE** สคริปต์ดึงให้ไม่ได้ อีเมลสรุปจะเตือนให้ใส่เอง (ถ้าคนส่งแนบอีเมลมาด้วย สคริปต์เก็บให้)
- **หน้าเว็บ “Playlist รายวัน”** (ต้องทำเพิ่มอีกขั้น ดูด้านล่าง): เห็นเช็กลิสต์ 10 แบบของวันนี้ กด **ดาวน์โหลด** ได้ไฟล์ .zip ไฟล์เดียว ลากลง PHOTO CHECK STUDIO ขั้นที่ 1 ได้เลยไม่ต้องแตกไฟล์ (ระบบ 4.1.1 ขึ้นไป) • มีปุ่ม **ดึงตอนนี้** • ดูย้อนหลังรายวันได้

สคริปต์ไม่ได้เติมใบเช็ครูป ส่วนนั้นยังทำใน PHOTO CHECK STUDIO เหมือนเดิม

## ติดตั้งครั้งแรก (ประมาณ 5 นาที)

ใช้บัญชี Google ที่รับอีเมล Playlist

1. เปิด https://script.google.com → กด **โครงการใหม่ (New project)**
2. ตั้งชื่อโครงการมุมซ้ายบน เช่น `ดึง Playlist อัตโนมัติ`
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` นี้ → กด **บันทึก** (ไอคอนแผ่นดิสก์)
4. (ไม่บังคับ) แก้ค่าในส่วน `CONFIG` ด้านบนของโค้ด
   - `notifyEmail` อีเมลที่จะรับสรุป หลายคนคั่นด้วยจุลภาค เว้นว่าง = ส่งหาตัวเอง
   - `parentFolderId` ถ้าอยากใช้โฟลเดอร์ Drive ที่มีอยู่แล้ว (เช่นโฟลเดอร์ที่แชร์ให้ทีม) ใส่ ID จากลิงก์ `drive.google.com/drive/folders/<ID>` เว้นว่าง = สร้างโฟลเดอร์ “Playlist รายวัน” ให้
   - `fromFilter` อีเมลผู้ส่ง Playlist เพื่อกรองให้แม่นขึ้น เช่น `a@company.com OR b@company.com`
5. แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้ (Run)**
6. ครั้งแรก Google จะถามสิทธิ์ → **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี
   - ถ้าขึ้นว่า “Google ยังไม่ได้ยืนยันแอปนี้” ให้กด **ขั้นสูง (Advanced)** → **ไปที่ ดึง Playlist อัตโนมัติ (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
     (เป็นสคริปต์ที่คุณสร้างเองในบัญชีตัวเอง ข้อความนี้ขึ้นกับสคริปต์ส่วนตัวทุกตัว)
   - สิทธิ์ที่ขอ: อ่าน Gmail (หาไฟล์แนบ), เก็บไฟล์ใน Drive, ส่งอีเมลสรุป, ตั้งเวลาทำงาน
7. ดูผลที่ **บันทึกการดำเนินการ (Execution log)** ด้านล่าง จะบอกลิงก์โฟลเดอร์ และวันนี้ได้กี่แบบแล้ว

เสร็จแล้ว สคริปต์จะทำงานเองทุกชั่วโมง ปิดหน้าเว็บได้เลย

ถ้ากด Run แล้วขึ้นว่าบริษัทไม่อนุญาตให้ใช้ Apps Script หรือไม่อนุญาตสิทธิ์ Gmail ต้องขอผู้ดูแล Google Workspace ของบริษัทเปิดให้

**ถ้าขึ้น “คุณไม่ได้รับอนุญาตให้เรียกใช้ ScriptApp.getProjectTriggers”** แปลว่าตอนอนุญาตยังไม่ได้ติ๊กสิทธิ์ “เรียกใช้เมื่อคุณไม่ได้อยู่” (หน้าขอสิทธิ์ของ Google ให้เลือกทีละช่อง)
กด Run `setup` อีกครั้ง ตอน Google ถามสิทธิ์ให้ติ๊ก **เลือกทั้งหมด** แล้วกดดำเนินการต่อ (โฟลเดอร์ที่สร้างไว้แล้วไม่สร้างซ้ำ)
ถ้าติ๊กครบแล้วยังขึ้นอยู่ แปลว่าบริษัทไม่อนุญาตสิทธิ์นี้ — ระหว่างนั้นใช้ `collectNow` ดึงเองได้ทุกเมื่อ

## หน้าเว็บ “Playlist รายวัน” (แนะนำ ทำครั้งเดียว ประมาณ 3 นาที)

**ติดตั้งสคริปต์ไว้แล้ว:** วางโค้ดใหม่ก่อน — เปิดโครงการ “ดึง Playlist อัตโนมัติ” → ลบโค้ดเดิมใน `Code.gs` ทั้งหมด → วางโค้ดจาก `Code.gs` ฉบับนี้ → กด **บันทึก** (ถ้าเคยแก้ค่าใน `CONFIG` ให้แก้ในโค้ดใหม่ด้วย) ไม่ต้องกด `setup` ใหม่

1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอนเฟือง ⚙ ข้าง “เลือกประเภท (Select type)” → **เว็บแอป (Web app)**
3. ตั้งค่า
   - คำอธิบาย (Description): `Playlist รายวัน`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **เฉพาะตัวฉันเอง (Only myself)**
     ถ้าอยากให้ทีมเปิดได้ด้วย เลือก **ทุกคนใน planbmedia.co.th** (ทุกคนในบริษัทที่มีลิงก์จะเห็นและดาวน์โหลด Playlist ในโฟลเดอร์นี้ได้)
4. กด **ทำให้ใช้งานได้ (Deploy)** → ถ้า Google ถามสิทธิ์ ให้กดอนุญาตเหมือนตอนติดตั้ง
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) → เปิดในเบราว์เซอร์ → **บุ๊กมาร์กไว้**
   เปิดหน้าเว็บครั้งแรกแล้ว อีเมลสรุปรอบถัดไปจะมีลิงก์ “เปิดหน้า Playlist รายวัน” ให้เอง

หน้าเว็บอ่านเฉพาะโฟลเดอร์ “Playlist รายวัน” ของสคริปต์นี้ ไม่แก้ไขหรือลบไฟล์ (ยกเว้นปุ่ม **ดึงตอนนี้** ที่ทำงานเหมือน `collectNow`)

**ถ้าแก้โค้ดภายหลัง:** การดึงรายชั่วโมงใช้โค้ดใหม่ทันทีที่บันทึก แต่หน้าเว็บยังเป็นโค้ดเดิมจนกว่าจะกด
**ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ (Manage deployments)** → ไอคอนดินสอ ✎ → เวอร์ชัน **เวอร์ชันใหม่ (New version)** → **ทำให้ใช้งานได้** (ลิงก์เดิมใช้ต่อได้)

## ใช้งานทุกวัน

1. รออีเมล “Playlist … 10/10 แบบ — ครบแล้ว”
2. กดลิงก์ **เปิดหน้า Playlist รายวัน** ในอีเมล (หรือเปิดจากบุ๊กมาร์ก) → ดูเช็กลิสต์ → กด **ดาวน์โหลด N ไฟล์ (.zip)**
   - ติ๊กไว้ให้แล้ว: Playlist ที่ระบบเติมใบเช็คใช้ แบบละ 1 ไฟล์ (มีฉบับแก้ = ไฟล์ที่เข้ามาล่าสุด) • Playlist เพิ่มเติมไม่ติ๊ก ติ๊กเองถ้าต้องการ
3. ดาวน์โหลด Metro LED จาก LINE
4. เปิด PHOTO CHECK STUDIO → ลากไฟล์ `Playlist_ปปปป-ดด-วว.zip` กับไฟล์ Metro LED ลงขั้นที่ 1 พร้อมกัน **ไม่ต้องแตกไฟล์** แล้วทำต่อตามปกติ

ยังไม่ได้ทำหน้าเว็บ: เปิดลิงก์โฟลเดอร์ในอีเมล → เลือกทุกไฟล์ → ดาวน์โหลด (Drive รวมเป็น .zip) → ลาก .zip ลงขั้นที่ 1 ได้เลยเหมือนกัน (ถ้ามีฉบับแก้หลายไฟล์ ให้ลบไฟล์ที่ไม่ใช้ออกจากโฟลเดอร์ก่อน)

ถ้าเครื่องมี Google Drive for desktop ซิงก์โฟลเดอร์ “Playlist รายวัน” อยู่แล้ว เปิดโฟลเดอร์ของวันนั้นในเครื่องแล้วลากไฟล์ได้เลย ไม่ต้องดาวน์โหลด

## คำสั่งที่ใช้บ่อย (เลือกฟังก์ชันแล้วกด Run)

- **`collectNow`** ดึงทันที ไม่ต้องรอรอบชั่วโมง (เช่น ไฟล์มาหลัง 18:00) — ในหน้าเว็บคือปุ่ม **ดึงตอนนี้**
- **`stopAll`** หยุดทำงานอัตโนมัติ (กลับมาใช้ใหม่ กด `setup` อีกครั้ง)
- **`setup`** กดซ้ำได้ ไม่สร้างโฟลเดอร์หรือตั้งเวลาซ้ำ

## ปรับแต่ง

- **ชื่อไฟล์ Playlist เปลี่ยน:** แก้ `pattern` ในรายการ `kinds` ดูชื่อไฟล์ที่ไม่ถูกเก็บได้ท้ายอีเมลสรุป (“ไฟล์ Excel อื่นของวันนี้”)
- **เปลี่ยนเวลา:** แก้ `startHour` / `endHour`
- **ใช้ร่วมกันหลายคน:** ให้ Playlist เข้ากล่องอีเมลเดียว รันสคริปต์ที่บัญชีนั้นตัวเดียว แชร์โฟลเดอร์ “Playlist รายวัน” ให้ทีม และใส่อีเมลทุกคนใน `notifyEmail`

## ข้อควรรู้

- ไฟล์อยู่ใน Gmail และ Google Drive ของบัญชีบริษัทเท่านั้น สคริปต์ไม่ได้ส่งไฟล์ไปที่อื่น
- Google จำกัดการทำงานของสคริปต์ต่อวัน การทำงานชั่วโมงละครั้งอยู่ในเกณฑ์ปกติ
- รอบที่ไม่มีไฟล์ใหม่ สคริปต์จบเร็วและไม่ส่งอีเมล
- ปุ่มดาวน์โหลดในหน้าเว็บส่งไฟล์มาทีละส่วนแล้วรวมเป็น .zip ในเบราว์เซอร์ (Playlist ทั้งวันรวมราว 20 MB อาจใช้เวลาครู่หนึ่ง ปุ่มบอกความคืบหน้า) ไฟล์ไม่ผ่านที่อื่น
- ถ้าดาวน์โหลดจากหน้าเว็บไม่ได้ ใช้ปุ่ม **เปิดใน Drive** แล้วดาวน์โหลดจากที่นั่นแทน
