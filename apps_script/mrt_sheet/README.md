# ใบเช็ครูป MRT บน Google Sheets (ทดลอง)

ใบเช็ครูป MRT แบบใหม่ ใช้ Google Sheets ในบัญชีบริษัท ไม่ต้องติดตั้งโปรแกรม ใบเช็ค Excel เดิมยังใช้คู่กันได้ระหว่างทดลอง

- **คนคัดรูป** เปิดชีตบนคอม พิมพ์เลขวันที่ถ่ายในช่องของจอเมื่อได้รูป (เหมือนใบเช็ค: พื้นดำตัวเลขขาว) หรือพิมพ์ `ไม่ฉาย` / `none` → ระบบจดว่าใครใส่ เมื่อไร ไว้ในโน้ตของช่อง คะแนนแต่ละจอขึ้นเอง
- **คนถ่ายรูป** เปิดลิงก์บนมือถือ (เข้าด้วยอีเมลบริษัท ดูได้อย่างเดียว) เห็นรายการที่ยังไม่ได้ถ่าย คะแนนแต่ละจอ และคะแนนรวม
- **ผู้ดูแล / หัวหน้า** ดูแท็บ "สรุปคะแนน" และกำหนดสิทธิ์ในแท็บ "ผู้ใช้และสิทธิ์"
- รายการหนังมาจากใบเช็ค Excel ที่ PHOTO CHECK STUDIO เติมให้ (ลากไฟล์ไปไว้ในโฟลเดอร์ Drive แล้วกดนำเข้า)
- ไม่ได้ใช้ AI ตอนทำงาน — เป็นสูตรในชีตและสคริปต์ธรรมดา

ไฟล์: `Code.gs` (สคริปต์ + หน้ารับใบเช็คจาก PHOTO CHECK STUDIO) • `Phone.html` (หน้ามือถือ)

## ติดตั้งครั้งแรก (ประมาณ 10 นาที ทำครั้งเดียว)

ใช้บัญชี Google ของบริษัท

1. เปิด Google Drive → **ใหม่ → Google ชีต** ตั้งชื่อ `ใบเช็ครูป MRT (ทดลอง)`
2. ในชีต เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจากไฟล์ `Code.gs` นี้
4. กด **＋ (เพิ่มไฟล์) → HTML** ตั้งชื่อว่า `Phone` (ไม่ต้องพิมพ์ .html) ลบของเดิม แล้ววางโค้ดจากไฟล์ `Phone.html`
5. แถบซ้าย **บริการ (Services) ＋** → เลือก **Drive API** → **เพิ่ม (Add)**
6. กด **บันทึก** (ไอคอนแผ่นดิสก์) แล้วกลับไปที่ชีต กด **รีเฟรช** → จะมีเมนู **ใบเช็ครูป** ด้านบน

## นำเข้าใบเช็ค

1. เมนู **ใบเช็ครูป → นำเข้าใบเช็ค Excel จาก Drive**
   - ครั้งแรก Google ถามสิทธิ์ → **ตรวจสอบสิทธิ์** → เลือกบัญชี → ถ้าขึ้นว่ายังไม่ได้ยืนยันแอป กด **ขั้นสูง → ไปที่โครงการ (ไม่ปลอดภัย) → อนุญาต** (เป็นสคริปต์ของคุณเอง)
   - ถ้ายังไม่มีไฟล์ ระบบสร้างโฟลเดอร์ **`ใบเช็ค MRT นำเข้า`** ใน Drive ให้ และขึ้นลิงก์โฟลเดอร์
2. ลากไฟล์ใบเช็ค MRT (`คุณ… MRT.xlsm`) ทุกไฟล์ลงโฟลเดอร์นั้น
3. กดเมนูนำเข้าอีกครั้ง → ได้แท็บละสถานี + แท็บ **สรุปคะแนน** + แท็บ **ผู้ใช้และสิทธิ์**

นำเข้าซ้ำได้ทุกวัน:
- วันที่ที่คนคัดรูปพิมพ์ไว้ในชีต**ไม่หาย** ช่องอื่นใช้เลขวันที่ถ่ายจากไฟล์ Excel ล่าสุด
- ถ้ามีหลายไฟล์ของคนเดียวกันในโฟลเดอร์ ใช้ไฟล์ที่แก้ล่าสุด
- ขึ้นรอบใหม่ (เช่นจาก 1–15 เป็น 16–30) ระบบถามก่อน กด **ใช่** → เก็บสำเนารอบเก่าไว้ใน Drive แล้วเริ่มใหม่
- ระบบรู้รอบจากวันที่ถ่ายในใบเช็ค (มีวันที่ 16 ขึ้นไป = รอบ 16–31) ถ้ายังไม่มี ใช้วันที่นำเข้า

## ส่งจาก PHOTO CHECK STUDIO (ไม่ต้องลากไฟล์ ไม่ต้องกดเมนู)

หลังเติมใบเช็คใน PHOTO CHECK STUDIO ถ้ามีใบเช็คที่ชื่อมีคำว่า MRT หน้าผลการเติมมีปุ่ม **ส่งเข้าใบเช็ค MRT** (กล่อง "ทำต่อ")

1. ครั้งแรก: วางลิงก์หน้ามือถือ MRT (เมนู **ใบเช็ครูป → ลิงก์หน้ามือถือคนถ่ายรูป**) แล้วกด **บันทึกลิงก์** — ระบบจำไว้ในเครื่องนั้น
2. กด **ส่งเข้าใบเช็ค MRT** → หน้าต่างเล็กของชีตเปิดขึ้น รับไฟล์ เก็บลงโฟลเดอร์ `ใบเช็ค MRT นำเข้า` (ทับไฟล์ชื่อเดิม ฉบับเก่าอยู่ในถังขยะ Drive) แล้วนำเข้าเหมือนเมนู → ปิดเองใน 3 วินาที
3. ใบเช็คเป็นรอบใหม่ → หน้าต่างนั้นถามก่อน: ขึ้นรอบใหม่ / นำเข้าในรอบเดิม / ยังไม่นำเข้า

- ส่งได้เฉพาะเจ้าของชีต และอีเมลในช่อง **ผู้ดูแลระบบ / หัวหน้า** ของแท็บผู้ใช้และสิทธิ์
- ครั้งแรกถ้า Chrome กันหน้าต่างเด้ง กดอนุญาตป๊อปอัปของหน้า PHOTO CHECK STUDIO
- หลังวางโค้ดเวอร์ชันนี้ ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ก่อน ปุ่มนี้ถึงจะใช้ได้

## สิทธิ์

แท็บ **ผู้ใช้และสิทธิ์** (ช่องสีเหลืองคือช่องที่ต้องกรอก):
- **ผู้ดูแลระบบ / หัวหน้า** — อีเมล คั่นด้วย `,` → แก้ได้ทุกอย่าง
- **อีเมลคนคัดรูป** ของแต่ละสถานี → ใส่วันที่ได้เฉพาะช่องของสถานีนั้น
- **อีเมลคนถ่ายรูป** ของแต่ละสถานี → หน้ามือถือแสดงเฉพาะสถานีของคนนั้น (คนถ่ายรูปไม่ต้องได้สิทธิ์ชีต)

กรอกแล้วกดเมนู **ใบเช็ครูป → ตั้งสิทธิ์ตามแท็บผู้ใช้** (ระบบแชร์ชีตให้อีเมลผู้ดูแลและคนคัดรูป และล็อกส่วนอื่นไว้)

## เผยแพร่หน้ามือถือ (ทำครั้งเดียว)

1. ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
2. ไอคอนฟันเฟือง → เลือก **เว็บแอป**
3. **เรียกใช้ในฐานะ: ฉัน** • **ผู้มีสิทธิ์เข้าถึง: ทุกคนในองค์กร (planbmedia.co.th)**
4. กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** → ส่งใน LINE ให้คนถ่ายรูป
   - ดูลิงก์ทีหลังได้จากเมนู **ใบเช็ครูป → ลิงก์หน้ามือถือคนถ่ายรูป**
5. แก้โค้ดภายหลัง: **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (ลิงก์เดิมใช้ต่อได้)

หน้ามือถืออ่านข้อมูลใหม่ทุกครั้งที่เปิด (กดปุ่ม **อัปเดต** มุมขวาบน) ข้อมูลช้าไม่เกิน 1 นาที

## หมายเหตุ

- คะแนนจอ = (ช่องที่มีเลขวันที่ถ่าย + ช่อง "ไม่ฉาย") ÷ จำนวนหนังในสถานี เหมือนสูตรในใบเช็ค Excel
- พิมพ์อย่างอื่นที่ไม่ใช่เลข 1–31 หรือ ไม่ฉาย ชีตขึ้นเตือน (สามเหลี่ยมแดงมุมช่อง) และไม่นับเป็นได้รูป
- ช่องที่ไฟล์ Excel เขียนว่า `none` นำเข้าเป็น "ไม่ฉาย" (สีเทา ไม่ต้องถ่าย)
- อย่าแก้ชื่อแท็บสถานี และอย่าลบแถว 1–5 ของแท็บสถานี (ระบบใช้หาเลขจอและคะแนน)
