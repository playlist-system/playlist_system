# รับฟีดแบ็กจากทีม (Google Apps Script)

ปุ่ม **แจ้งปัญหา** ในหัวหน้า PHOTO CHECK STUDIO ส่งคำแจ้งของทีม (ข้อความยาวไม่จำกัด + รูป + ไฟล์ใบเช็คถ้าแนบ) เข้า Google Drive ของบริษัท ผ่านสคริปต์ `feedback.gs` — ไม่มีค่าใช้จ่าย ไม่ผ่านบริการภายนอก

## ได้อะไร

- โฟลเดอร์ **ฟีดแบ็ก PHOTO CHECK STUDIO** ใน Drive ของบัญชีที่ตั้งสคริปต์
  - ตาราง **คำแจ้งจากทีม** — 1 แถวต่อเรื่อง: เลขที่ วันที่ส่ง ผู้แจ้ง เรื่อง ใบ/ชีต/จอ รายละเอียดย่อ จำนวนรูป ลิงก์โฟลเดอร์ สถานะ (เปลี่ยนเองได้ เช่น ใหม่ / กำลังแก้ / แก้แล้ว)
  - โฟลเดอร์ย่อยต่อเรื่อง `#0001 …` — ข้อความเต็ม.txt, รูปที่แนบ, ไฟล์ใบเช็ค (ถ้าแนบ), ข้อมูลระบบ.txt

## ตั้งค่าครั้งเดียว (ประมาณ 5 นาที)

1. เปิด [script.google.com](https://script.google.com) ด้วยบัญชี Google ของบริษัท → **New project** ตั้งชื่อ เช่น `PHOTO CHECK STUDIO ฟีดแบ็ก`
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจาก `feedback.gs` → กดบันทึก
3. เลือกฟังก์ชัน **setup** ด้านบน → กด **Run** → Google ขออนุญาต (Drive / Sheets) → อนุญาต
4. **Deploy → New deployment** → ชนิด **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (ทีมส่งได้โดยไม่ต้องล็อกอิน — ถ้าบริษัทไม่เปิดให้เลือก Anyone บอกคนดูแลระบบ)
5. กด **Deploy** → คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/…/exec`) ส่งให้คนดูแลระบบใส่ในระบบ

ทดสอบ: เปิด Web app URL ในเบราว์เซอร์ ต้องเห็น `{"ok":true,"ready":true,...}`

## หมายเหตุ

- แก้โค้ดภายหลัง: Deploy → Manage deployments → แก้ deployment เดิม → Version: New version (URL เดิมใช้ต่อได้)
- รูปที่แนบและไฟล์ใบเช็คมีข้อมูลแคมเปญของลูกค้า — เก็บใน Drive ของบริษัทเท่านั้น อย่าแชร์โฟลเดอร์นี้ออกนอกบริษัท
