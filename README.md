# ระบบเติมใบเช็ครูปอัตโนมัติ

เครื่องมือแปลง Playlist รายวัน เป็นใบเช็ครูป (.xlsm) ของผู้ตรวจแต่ละคน
ไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ (Chrome / Edge) ได้เลย ไม่ต้องติดตั้ง ทำงานออฟไลน์
ไฟล์ทั้งหมดประมวลผลในเครื่องผู้ใช้ ไม่ถูกส่งออกไปที่ใด

**เวอร์ชัน 3.8.3 · 20 ต.ค. 2569**

## วิธีเปิด

- **เปิดจากลิงก์:** https://playlist-system.github.io/playlist_system/
- หรือดาวน์โหลด `playlist_system.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ (ใช้แบบออฟไลน์ได้)

## วิธีใช้ประจำวัน

1. **ใส่ Playlist** — ถ้ามีของวันก่อนค้างอยู่ กด “ล้าง Playlist (เริ่มวันใหม่)” แล้วลากไฟล์ Playlist ของวันนั้นทั้งหมดลงกล่อง
   เช็กลิสต์ 11 ช่องจะสว่างทีละแบบเมื่อได้ไฟล์ (สรุปรายการหนังแยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Signature Max • Show DC • BKJ1 • BKJ2 • Metro LED)
   ถ้ามีใบเช็ค CCTV / MRT / LA PlanB ใส่ Playlist เพิ่มเติมด้วย (ไม่นับใน 11 แบบ): Rama9 Connect • Digital MRT • Gateway X • Air Traveller • The 20 • LA PlanB (ไม่ได้ส่งทุกวัน ใส่ฉบับล่าสุดที่มี)
2. **ตรวจ / แก้ไข** (ไม่บังคับ) — ปลด เพิ่ม หรือเปลี่ยนชื่อหนังก่อนเติม
3. **เติมใบเช็ครูป** — ลากใบเช็ครูปของวันก่อนหน้าลงกล่อง (ทุกคนหรือเฉพาะของตัวเอง) ระบบบอกว่าแต่ละไฟล์ “พร้อมเติม” หรือยังขาด Playlist แบบไหน ตรวจวันที่ทำงานและรอบ เปิด “จัดรูปแบบตามใบเช็คจริง” ไว้ (ค่าเริ่มต้น) แล้วกด “เติมใบเช็ครูป”
   ตัวเลือกอื่นในขั้นนี้มีคำอธิบายและค่าแนะนำอยู่ใต้ตัวเลือกแต่ละตัว ถ้าเปลี่ยนจากค่าแนะนำ ระบบเตือนก่อนเติม
4. **ผลการเติม** — ดูรายการ “ควรตรวจ” ของแต่ละไฟล์ แล้วกด “ดาวน์โหลดทั้งหมด (.zip)”
   ไฟล์ที่ได้คือใบเช็คของวันนี้ และเป็นไฟล์ตั้งต้นของวันพรุ่งนี้
   **สร้างโฟลเดอร์แยกรูป** (Chrome / Edge, 3.7): กด “เลือกโฟลเดอร์แยกรูปแล้วตรวจ” (เลือกครั้งแรกครั้งเดียว) ดูว่าจะสร้างอะไร แล้วกด “สร้าง … โฟลเดอร์”
   **ตรวจโฟลเดอร์เทียบจอ** (Chrome / Edge, 3.8): กด “เลือกโฟลเดอร์เทียบจอแล้วตรวจ” เลือกโฟลเดอร์ที่มีโฟลเดอร์รอบ (เช่น 10 Oct 16-31) ระบบบอกเป็นข้อ ๆ ว่าต้องแก้ในใบเช็ค หรือต้องแก้ในโฟลเดอร์

ตัวช่วยมุมขวาบน: **“ระบบทำงานอย่างไร”** (ภาพรวมสำหรับคนที่ยังไม่รู้จักระบบ) • **“แนะนำการใช้”** (ทัวร์ชี้ทีละจุด) • **“วิธีใช้”** (ขั้นตอน กฎ และความหมายของ “ควรตรวจ”) • สลับโหมดสว่าง / มืด
คู่มือฉบับเต็มสำหรับเปิดใน Notepad: [`คู่มือการใช้งาน_ระบบเติมใบเช็ครูป.txt`](คู่มือการใช้งาน_ระบบเติมใบเช็ครูป.txt)

## กฎที่ระบบใช้จัด

- วันที่ 1 ลงหนังที่ออนอยู่ทั้งหมด หนัง # ขึ้นก่อน (ไฮไลต์เหลือง) แล้วเรียง A–Z
- วันถัดไป หนังที่ยังไม่มีในใบเช็คและสถานะ “ขึ้นใหม่” ลงใต้แถบวันที่ของวันนั้น หนังที่มีอยู่แล้วอยู่ที่เดิม ไม่ซ้ำ • หมายเหตุ “ออนแอร์ระหว่างวันวันที่ …” ลงใต้แถบวันนั้น (ครึ่งเดือนหลัง: หนังใหม่ที่หมายเหตุลงวันที่ 1–15 ลงใต้แถบ 16 เพราะรอบ 1–15 ปิดแล้ว)
- หนังที่ยังอยู่ใน Playlist ถือว่ายังออนอยู่ แม้วันหมดในไฟล์ผ่านไปแล้ว • “ออกวันที่ N” ใส่เมื่อหนังย้ายไปอยู่ในรายการถอด (วันที่ 1 ยังไม่ใส่) • ไฟล์เดิม / ต่อสัญญากลางรอบ ใช้แถวเดิม
- คำในช่องออกเขียนแบบเดียวกับที่ใบเช็คใช้อยู่ (3.5): ใบที่เขียน “ออก 5” ได้ “ออก N” ใบที่เขียน “ออกวันที่ 5” ได้ “ออกวันที่ N” ชีตที่ยังไม่มีหมายเหตุใช้แบบของชีตอื่นในไฟล์เดียวกัน (ทั้งไฟล์ยังไม่มีเลย ใช้ “ออกวันที่ N”) • รหัสจอที่ขีดต่างจาก Playlist (ใบเช็ค DGT-174 / Playlist DGT174) จับคู่ให้ในสื่อเดียวกัน และบอกในผลการเติม • หนัง Content ที่ใบเช็คเขียนไว้แล้วแบบไม่มี # ใช้แถวเดิม ไม่เพิ่มแถว # ซ้ำ
- วันที่ถ่าย (ช่องหลังชื่อหนังที่ทีมใส่เอง) ย้ายตามชื่อหนังให้เอง **ทุกคอลัมน์** — จอที่มีหลายจอในบล็อกเดียว (Bangkok Jam 1, Bangkok Jam 2-A, Metro LED) ก็ย้ายครบทุกจอ • ขึ้นเดือนใหม่ (เติมวันที่ 1) ล้างวันที่ถ่ายของเดือนก่อนทุกคอลัมน์ • ระบบดูแลแค่รายชื่อหนังกับ “ออกวันที่” ไม่เขียนวันที่ถ่ายเอง
- **วันที่ 16 เป็นต้นไปทำต่อในรายการเดิม** (แบบที่ทีมทำ): หนังที่ต่อสัญญา / ขึ้นใหม่วันที่ 16 ลงแถวใหม่ใต้แถบ 16 แถวเดิมใส่ “ออกวันที่ 16” แถบวันที่ 16 เป็นต้นไปเป็นอีกสี (เลือกสีได้ ค่าเริ่มต้นใช้สีเดิมของชีต หรือสีฟ้า) • หนังที่ลงไว้ช่วง 1–15 ออกไปแล้วกลับมา “ขึ้นใหม่” ในครึ่งหลัง ลงแถวใหม่ใต้วันนั้น • ถ้าต้องการเริ่มรายการใหม่ตอนวันที่ 16 แบบเวอร์ชัน 2.3 เลือกได้ใน “ตัวเลือกเพิ่มเติม”
- อ่านหมายเหตุใน Playlist: ไม่ออน / ออนเฉพาะ / เฉพาะจอ / ทุกจอยกเว้น (Signature Max, Show DC — เทียบชื่อย่อจอ เช่น SO, TWT, สาทร, AOT, BIGY, PJ, AN, EXT, SDC; The Big Y ไม่นับเป็น AOT), ขึ้นเฉพาะ / ยกเว้นจอ และชื่อ “_Screen12and32” (BKJ เทียบเลขจอที่หัวคอลัมน์), Tags `LEDMETRO_030` / `!LEDMETRO_030` (Metro LED)
- ตัดแถวที่ไม่ใช่หนัง เช่น “เริ่มออน…”, “รอ Memo”, “On 1 Sep 26”, Content ที่ไม่มีจำนวนครั้ง และตัด “(O/A 1 วัน)” ท้ายชื่อ
- แถบท้ายตารางเป็นวันถัดไป — ทำตามแบบของแต่ละใบ (3.6): ใบที่ใส่แถบวันถัดไปรอไว้ ระบบใส่ให้ ใบที่ไม่ใส่ (แถบสุดท้ายมีหนังอยู่ข้างใต้) ระบบก็ไม่ใส่ • วันที่ในแถบของจอที่ 2 เป็นต้นไปเป็นสูตร (=C25) หรือตัวเลขตามที่ใบนั้นใช้ • หนังต่อสัญญาวันที่ 16: ใบที่แถวเดิมไม่ใส่ “ออก 16” ติ๊กตัวเลือกใต้ชื่อไฟล์ในขั้นที่ 3 (ระบบจำไว้ตามชื่อไฟล์ ค่าเริ่มต้นใส่ “ออก 16” แบบเดิม)
- **Metro LED** (3.1): สถานะอ่านจากสีแถวตามคำอธิบายสีในหัวชีต — เหลือง (ไฟล์ใหม่) = ขึ้นใหม่, ส้ม (ไฟล์เก่ากลับมาออกอากาศใหม่) = ขึ้นใหม่ไฟล์เดิม, ฟ้าอ่อน = ต่อสัญญา • อ่านระยะสัญญา (Start–End) ด้วย วันเริ่มใช้วันที่ช้ากว่าระหว่างเริ่มออกอากาศกับเริ่มสัญญา (สัญญาใหม่เริ่ม 16 → ลงใต้แถบ 16 แถวเดิมใส่ “ออกวันที่ 16”) และแสดงระยะสัญญาในขั้นที่ 2
- แถว #FAST_ADS / FastAd ไม่ใช่หนังโฆษณา: ไม่ใส่จาก Playlist และลบออกจากใบเช็คตอนเติม (บอกจำนวนในรายงาน)
- **Playlist เพิ่มเติม** (3.4): Rama9 Connect, Digital MRT (18 สถานีเดิม / ส่วนต่อขยาย 20 สถานี), Gateway X ไม่มีช่องสถานะ — ช่องชื่อหนังสีเหลือง = ขึ้นใหม่, สีชมพู = ขึ้นใหม่ไฟล์เดิม, กลุ่ม AD.ออก / Ads ถอด = หนังที่ถอด, Content อาคาร / Content Plan B ไม่ลงใบเช็ค, Content อื่น (เช่น Content กทพ.) ลงเป็นหนัง #, แถวที่ยังไม่มีชื่อไฟล์ (“Onair 19/10/2026”) ไม่ใส่ • Air Traveller (IN / OUT) และ The 20 อ่านแบบ Signature Max แต่เป็นสื่อของตัวเอง ไม่ใส่โฆษณา Programmatic (Vistar) • ไฟล์ .xls และชื่อไฟล์แบบ 20261016 อ่านได้
- **ใบเช็คแบบใหม่** (3.4): CCTV, MRT (แยกชีตตามสถานี — สถานีส่วนต่อขยายท่าพระ–หลักสอง / เตาปูน–ท่าพระใช้รายการส่วนต่อขยาย สถานีอื่นใช้ 18 สถานีเดิม), Gateway X, Rama9 Connect, Air Traveller (To Airport = IN, To City = OUT) และ THE 20 — แถวสูตรวิเคราะห์อยู่แถว 10 ตารางเริ่มแถว 17 หรือ 23 ระบบหาเอง • ชีต CCTV ที่มีทั้งจอ DGT และจอ Signature Max (Air Traveller Gateway) เติมครบทุกจอ • ช่องหมายเหตุที่ทีมพิมพ์ต่อท้ายจอสุดท้าย (เช่น “กลับมาออนใหม่วันที่ 12”) ย้ายตามชื่อหนัง • “ออก N” เขียนแบบเดียวกับที่ชีตใช้อยู่ (“ออก 5” หรือ “ออกวันที่ 04”)
- **LA PlanB** (3.5): Playlist “รายการโฆษณาประจำวันสื่อ LA PlanB เริ่มตั้งแต่ …” ส่งเฉพาะวันที่รายการเปลี่ยน ใส่ฉบับล่าสุดที่มีได้ทุกวัน (เช็กลิสต์ขึ้น “ใช้ฉบับล่าสุดที่มี” ไม่นับเป็นไฟล์หลายวันปนกัน และไม่ใช้กำหนดวันทำงาน) วันของไฟล์อ่านจากในไฟล์ (แถว 2 / “เริ่มตั้งแต่”) • ชีต LA PLANB: จอ LA PlanB 1 และ 2 ใช้รายการเดียวกัน หนังใน “รายการปลด” ใส่ออกเป็นวันที่ไฟล์ใหม่เริ่ม หนังใหม่ลงใต้แถบวันนั้น
- **โฟลเดอร์แยกรูป** (3.7): `แยกรูป\Pic @ สื่อ\จอ\10 OCT 26\1-15 หรือ 16-30 / 16-31\ชื่อหนัง` — สร้างเฉพาะรอบปัจจุบันจากใบเช็คที่เพิ่งเติม: รอบ 1–15 = หนังใต้แถบวันที่ 1–15, รอบ 16–สิ้นเดือน = หนังใต้แถบ 16 ขึ้นไป (แบบที่ทีมทำ) พร้อม #Module ขาว / ดำ / สี และโฟลเดอร์เดือน / รอบถ้ายังไม่มี • จับคู่จอกับโฟลเดอร์จากรหัส DGT / ID หน้าชื่อโฟลเดอร์, เลขจอ BKJ1_04 / BKJ2_20 / METRO_07 ในหัวคอลัมน์ หรือชื่อจอ (So Bangkok, Twin Tube, The Big Y, BASE, Eastin Makkasan) จอที่มีโฟลเดอร์ 2 ที่ใช้ที่มีโฟลเดอร์เดือนอยู่แล้ว • ไม่ลบ ไม่ย้าย ไม่เปลี่ยนชื่อ ไม่สร้างโฟลเดอร์จอเอง (จอที่หาไม่เจอแจ้งในรายการ) และไม่แตะจอปิดถาวร • กดซ้ำได้ทุกวัน สร้างเฉพาะเรื่องที่ยังไม่มี
- **ตรวจโฟลเดอร์เทียบจอ** (3.8): `เทียบจอ Plan B TV BKK\10 Oct 16-31\Plan B TV 80 RED\DGT001 …` — อ่านอย่างเดียว เทียบใบเช็ครูปที่เติมแล้วกับโฟลเดอร์ในเครื่อง: จอในชีต 40 BLUE / 40 RED / 80 BLUE / 80 RED / CITY / Spare ต้องมีโฟลเดอร์ในโฟลเดอร์แพคเดียวกัน (Plan B TV 40 BLUE … / CITY TV 25 / Spare) • รายการที่บอก: ใบเช็คกับโฟลเดอร์อยู่คนละแพค, จอในใบเช็คที่ไม่มีโฟลเดอร์, ใบเช็คใส่จอเดียวกันไว้คนละแพค, มีโฟลเดอร์เกินในแพคอื่น, จอเดียวกันมีโฟลเดอร์หลายแพค, ชื่อจอในโฟลเดอร์รวม Plan B TV 240 ที่ไม่ตรงกับชื่อในโฟลเดอร์แพค (3.8.2: 240 ใช้ดูรายชื่อจอ ระบบตรวจแค่ชื่อ ไม่ตัดสินแพคจาก 240 — ขึ้นทั้งสองชื่อให้เทียบ) • ผลแยกเป็นกลุ่ม (3.8.1): ต้องแก้ในใบเช็ค / ต้องแก้ในโฟลเดอร์ / ให้ตรวจเอง / ชื่อจอใน Plan B TV 240 แต่ละจอบอกสิ่งที่ต้องทำประโยคเดียว ระบบใช้ Playlist วันนี้ตัดสินว่าฝั่งไหนผิด (บอกไม่ได้ = ให้ตรวจเอง) • โฟลเดอร์รอบหาจากวันทำงาน (ชื่อแบบ `10 Oct 1-15` / `10 Oct 16-31` อยู่ในโฟลเดอร์ที่เลือก ลึกไม่เกิน 3 ชั้น หรือเลือกโฟลเดอร์รอบเลยก็ได้) ถ้ายังไม่มีรอบใหม่ใช้รอบล่าสุด • โฟลเดอร์จอที่ไม่มีในใบเช็คที่เติม ไม่ได้เทียบกับใบเช็ค (ใส่ใบเช็คของทุกคนจะตรวจได้ครบ) ส่วนชื่อจอใน 240 ตรวจกับโฟลเดอร์แพคครบทุกจอ
