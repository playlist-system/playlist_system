# ระบบเติมใบเช็ครูปอัตโนมัติ

เครื่องมือแปลง Playlist รายวัน เป็นใบเช็ครูป (.xlsm) ของผู้ตรวจแต่ละคน
ไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ (Chrome / Edge) ได้เลย ไม่ต้องติดตั้ง ทำงานออฟไลน์
ไฟล์ทั้งหมดประมวลผลในเครื่องผู้ใช้ ไม่ถูกส่งออกไปที่ใด

**เวอร์ชัน 2.1 · 12 ต.ค. 2569**

## วิธีเปิด

- **เปิดจากลิงก์:** https://playlist-system.github.io/playlist_system/
- หรือดาวน์โหลด `playlist_system.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ (ใช้แบบออฟไลน์ได้)

## วิธีใช้ประจำวัน

1. **ใส่ Playlist** — ถ้ามีของวันก่อนค้างอยู่ กด “ล้าง Playlist (เริ่มวันใหม่)” แล้วลากไฟล์ Playlist ของวันนั้นทั้งหมดลงกล่อง
   เช็กลิสต์ 11 ช่องจะสว่างทีละแบบเมื่อได้ไฟล์ (สรุปรายการหนังแยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Signature Max • Show DC • BKJ1 • BKJ2 • Metro LED)
2. **ตรวจ / แก้ไข** (ไม่บังคับ) — ปลด เพิ่ม หรือเปลี่ยนชื่อหนังก่อนเติม
3. **เติมใบเช็ครูป** — ลากใบเช็ครูปของวันก่อนหน้าลงกล่อง (ทุกคนหรือเฉพาะของตัวเอง) ระบบบอกว่าแต่ละไฟล์ “พร้อมเติม” หรือยังขาด Playlist แบบไหน ตรวจวันที่ทำงานและรอบ แล้วกด “เติมใบเช็ครูป”
4. **ผลการเติม** — ดูรายการ “ควรตรวจ” ของแต่ละไฟล์ แล้วกด “ดาวน์โหลดทั้งหมด (.zip)”
   ไฟล์ที่ได้คือใบเช็คของวันนี้ และเป็นไฟล์ตั้งต้นของวันพรุ่งนี้

ตัวช่วยมุมขวาบน: **“ระบบทำงานอย่างไร”** (ภาพรวมสำหรับคนที่ยังไม่รู้จักระบบ) • **“แนะนำการใช้”** (ทัวร์ชี้ทีละจุด) • **“วิธีใช้”** (ขั้นตอน กฎ และความหมายของ “ควรตรวจ”) • สลับโหมดสว่าง / มืด
คู่มือฉบับเต็มสำหรับเปิดใน Notepad: [`คู่มือการใช้งาน_ระบบเติมใบเช็ครูป.txt`](คู่มือการใช้งาน_ระบบเติมใบเช็ครูป.txt)

## กฎที่ระบบใช้จัด

- วันแรกของรอบ (วันที่ 1 และ 16) ลงหนังที่ออนอยู่ทั้งหมด หนัง # ขึ้นก่อน (ไฮไลต์เหลือง) แล้วเรียง A–Z
- วันถัดไป หนังที่ยังไม่มีในใบเช็คและสถานะ “ขึ้นใหม่” ลงใต้แถบวันที่ของวันนั้น หนังที่มีอยู่แล้วอยู่ที่เดิม ไม่ซ้ำ
- “ออกวันที่ N” ใส่เมื่อถึงวันที่หนังออก (วันที่ 1 ยังไม่ใส่) ไฟล์เดิม / ต่อสัญญา ไม่ใส่ออกวันที่และไม่เพิ่มแถวซ้ำ
- ตัวเลขที่ผู้ตรวจนับไว้ ย้ายตามชื่อหนังให้เอง
- วันที่ 16 เริ่มรอบใหม่เป็นแถบสีเขียวต่อท้ายในชีตเดิม ไม่แตะรอบ 1–15 • แถบท้ายตารางเป็นวันถัดไปเสมอ
