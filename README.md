## หน้าจอ (4.0)

- **แท็บด้านบน:** “เติมใบเช็ครูป” (งานประจำวัน) • “งานโฟลเดอร์และรูป” • “วิธีใช้” — มุมขวาบนบอกวันที่ของ Playlist และรอบ มีปุ่มหน้ายิ้มเปิด / ปิดน้องโฟกัส และปุ่มสลับโหมดสว่าง / มืด
- **เมนูด้านซ้าย:** ขั้นของส่วนที่เปิดอยู่ บอกว่าแต่ละขั้นทำไปถึงไหน (เครื่องหมายถูก = ทำแล้ว) กดเพื่อไปขั้นนั้น • ใต้เมนูมี “ระบบทำงานอย่างไร” และ “แนะนำการใช้” • บนมือถือ เมนูนี้เป็นแถบเลื่อนด้านบน
- **หน้าหลัก** (เปิดระบบมาเจอหน้านี้ก่อน • จัดใหม่ 5.1): หัวข้อใหญ่บอกว่าวันนี้ถึงไหนแล้ว (เช่น “พร้อมเติม 6 ไฟล์”) • **กล่องไฟล์ของวันนี้** ลากไฟล์มาวางได้ มีป้าย Playlist (กี่แบบจาก 11 กี่จอ) / ใบเช็ครูป (กี่ไฟล์ ควรดูกี่เรื่อง) / วันที่ถ่าย / ผลการเติม กดป้ายเพื่อไปขั้นนั้น ปุ่ม + เลือกไฟล์ ปุ่มใหญ่พาไปสิ่งที่ควรทำต่อ • ทางลัดไปเครื่องมือในหน้างานโฟลเดอร์และรูป • **เรื่องที่ควรดู** (ก่อนเติม = คำเตือนเดียวกับขั้นที่ 3 • หลังเติม = รายการต้องแก้) • ตาราง “ใบเช็ครูปวันนี้” (กดแท็บเพื่อกรอง) • **บันทึกการทำงาน** ของรอบนี้ • ไฟล์ Playlist ที่ใส่แล้ว • ผลการเติมล่าสุด (ดาวน์โหลด / บันทึกทับได้จากตรงนี้)
- **ค้นหา (Ctrl K)** (5.1): ปุ่ม “ค้นหา” มุมขวาบน หรือกด Ctrl K (Mac: ⌘ K) ทุกหน้า — พิมพ์รหัสจอ (เช่น DGT118) ชื่อจอ ชื่อไฟล์ใบเช็ค หรือชื่อเครื่องมือ • จอใน Playlist บอกสื่อ จำนวนรายการ และอยู่ในใบเช็คของใคร กดเพื่อเปิดจอนั้นในขั้นที่ 2 • ค้นในเครื่องนี้เท่านั้น
- **ลากไฟล์มาวางที่หน้าหลักได้เลย** ใส่ Playlist และใบเช็คปนกันได้ ระบบแยกให้เอง (.xlsm = ใบเช็ค)

## วิธีใช้ประจำวัน

1. **ใส่ Playlist** — ถ้ามีของวันก่อนค้างอยู่ กด “ล้าง Playlist (เริ่มวันใหม่)” แล้วลากไฟล์ Playlist ของวันนั้นทั้งหมดลงกล่อง — ไฟล์ .zip (จากหน้าเว็บ Playlist รายวัน หรือดาวน์โหลดทั้งโฟลเดอร์จาก Google Drive) ลากลงได้เลย ไม่ต้องแตกไฟล์
   เช็กลิสต์ 11 ช่องจะสว่างทีละแบบเมื่อได้ไฟล์ (สรุปรายการหนังแยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Signature Max • Show DC • BKJ1 • BKJ2 • Metro LED)
   ถ้ามีใบเช็ค CCTV / MRT / LA PlanB ใส่ Playlist เพิ่มเติมด้วย (ไม่นับใน 11 แบบ): Rama9 Connect • Digital MRT • Gateway X • Air Traveller • The 20 • LA PlanB (ไม่ได้ส่งทุกวัน ใส่ฉบับล่าสุดที่มี)
   **หยุดหลายวัน (เช่น เสาร์–อาทิตย์)** — ลาก .zip ของทุกวันที่หยุดลงพร้อมกัน ระบบเรียงวันในกล่อง “ใส่ Playlist ไว้ … วัน” ตอนกดเติม ระบบเติมต่อกันทีละวันเอง (ใบเช็คที่ได้ของวันหนึ่งเป็นไฟล์ตั้งต้นของวันถัดไป) กดเติมครั้งเดียว บันทึกครั้งเดียว ผลเหมือนเติมทีละวัน • ขาดวันไหน หรือใบเช็คเติมล่าสุดไม่ถึงวันก่อนหน้า ระบบเตือนก่อนเติม
   **กันเติมย้อนหลัง (4.7)** — ถ้า Playlist เป็นวันก่อนวันที่บันทึกใบเช็คครั้งล่าสุด ขั้นที่ 3 เตือนก่อนเติม • ตอนเติม ชีตที่เติมไปถึงวันหลังกว่า Playlist แล้ว (มีหนังใต้แถบวันที่หลังกว่า หรือมี “ออก …” วันที่หลังกว่า) ระบบไม่แก้ทั้งไฟล์ ไฟล์ที่ได้เหมือนเดิมทุกอย่าง และบอกใน “ควรตรวจ”
2. **ตรวจ / แก้ไข** (ไม่บังคับ) — ปลด เพิ่ม หรือเปลี่ยนชื่อหนังก่อนเติม
3. **เติมใบเช็ครูป** — ลากใบเช็ครูปของวันก่อนหน้าลงกล่อง (ทุกคนหรือเฉพาะของตัวเอง) ระบบบอกว่าแต่ละไฟล์ “พร้อมเติม” หรือยังขาด Playlist แบบไหน ตรวจวันที่ทำงานและรอบ เปิด “จัดรูปแบบตามใบเช็คจริง” ไว้ (ค่าเริ่มต้น) แล้วกด “เติมใบเช็ครูป”
   สวิตช์ “เพิ่มหนังกันตกหล่นให้เอง” (4.5 ค่าเริ่มต้นปิด ระบบจำไว้ในเครื่องนี้) — เปิดแล้ว หนังที่มีใน Playlist แต่ยังไม่เคยลงใบเช็คของจอนั้น และวันนี้ไม่ได้ “ขึ้นใหม่” ระบบลงให้ใต้แถบวันที่ที่เติม และบอกใน “ควรตรวจ”
   ตัวเลือกอื่นในขั้นนี้มีคำอธิบายและค่าแนะนำอยู่ใต้ตัวเลือกแต่ละตัว ถ้าเปลี่ยนจากค่าแนะนำ ระบบเตือนก่อนเติม
4. **ผลการเติม** — (5.2: หัวหน้าบอก “เติมเสร็จ … จอ” พร้อมปุ่มดาวน์โหลด / บันทึกทับ • การ์ดสรุปเป็นประโยค • “ต้องแก้” เรียงเป็นข้อ กด “ดูในไฟล์” • “แจ้งให้ทราบ” แยกตามประเภท • ด้านข้างบอกเติมแต่ละไฟล์ / ทีละวัน และทางไปต่อ) ดูรายการ “ต้องแก้” ของแต่ละไฟล์ (4.9: รายการควรตรวจแบ่งเป็น **ต้องแก้** = จอที่เติมไม่ได้ เติมจากรายการอื่นแทน จอขาด ชีตที่ข้าม และ **แจ้งให้ทราบ** = หนังที่ระบบตั้งใจไม่ใส่ / ยังไม่ถึงวันเริ่ม / กันตกหล่น ซึ่งพับไว้ ไม่ต้องแก้) แล้วกด “ดาวน์โหลดทั้งหมด (.zip)”
   ไฟล์ที่ได้คือใบเช็คของวันนี้ และเป็นไฟล์ตั้งต้นของวันพรุ่งนี้
   เติมเสร็จแล้ว จะสร้างโฟลเดอร์แยกรูป ใส่วันที่ถ่าย หรือตรวจโฟลเดอร์เทียบจอ กด “ไปหน้างานโฟลเดอร์และรูป” ใต้รายการไฟล์ (ดูด้านล่าง)

### หน้า “งานโฟลเดอร์และรูป” (Chrome / Edge, 3.13)

กดแท็บ **“งานโฟลเดอร์และรูป”** ด้านบน (กลับมาเติมใบเช็ค กดแท็บ “เติมใบเช็ครูป” — งานที่ค้างไว้ไม่หาย) ไม่ต้องใส่ Playlist • เมนูด้านซ้ายมี “ภาพรวม” และเครื่องมือทั้ง 3 พร้อมสถานะ (4.0)
กล่อง **“ใบเช็คที่ใช้”** คือชุดที่ทุกเครื่องมือในหน้านี้อ่าน: เพิ่งเติมเสร็จ → ใช้ใบที่เพิ่งเติมให้เอง • ยังไม่เติม → ใช้ใบในขั้นที่ 3 • หรือกด “เปิดใบเช็คทั้งโฟลเดอร์” / ลากไฟล์มาวาง — เลือกแล้วระบบอ่านรายชื่อหนังให้ทันที
การ์ด 3 ใบ (3.14) บอกสถานะของแต่ละเครื่องมือด้วยตัวเลขใหญ่และสี (เหลือง = รอทำ เขียว = เรียบร้อย แดง = ต้องแก้) กด **“เปิด”** แล้วทำงานนั้นด้านล่างทีละอย่าง

- **ดาวน์โหลดโครงโฟลเดอร์แยกรูป (.zip)** (5.5): ไม่ต้องเลือกโฟลเดอร์ ใช้ได้ทุกเบราว์เซอร์ — ได้โฟลเดอร์ว่างแบบ Gallary: Pic @ แพค → รอบ (`11 Nov 2026 1-15`) → จอ (ชื่อจากใบเช็คของแต่ละคน เช่น `DGT213 สถานที่ (40B) (VR4B)`, `BKJ1_04 @ สถานที่`, `METRO_07 @ สถานที่`) → **#Fast Ads, #Module ขาว / ดำ / สี** และหนังทุกเรื่องของรอบ • เปิด .zip แล้วคัดลอกโฟลเดอร์ Pic @ ไปวางในโฟลเดอร์ Gallary (โฟลเดอร์ที่มีอยู่แล้วจะรวมกัน) • ชีตที่ไม่บอกแพคใช้แพคและสถานที่จากฐานข้อมูลจอ (ถ้าใส่ไว้) • จอห้าง / แพคที่ไม่รู้ ไม่ใส่ บอกรายชื่อไว้ • **ชื่อโฟลเดอร์จอเลือกได้ 2 แบบ** (5.5.1): “ตามใบเช็ค” หรือ “ตามโฟลเดอร์ที่มีอยู่” (Chrome / Edge: เลือกโฟลเดอร์ Gallary / แยกรูปครั้งแรกครั้งเดียว ระบบอ่านอย่างเดียว ใช้ชื่อจอเดิมทุกตัวอักษร จอที่ยังไม่มีโฟลเดอร์ใช้ชื่อจากใบเช็ค จอปิดถาวรไม่ใส่)
- **สร้างโฟลเดอร์แยกรูป** (3.7 • 5.5 สร้างโฟลเดอร์จอที่ยังไม่มีให้ด้วย ชื่อจากใบเช็ค และสร้าง #Fast Ads ทุกจอ): กด “เลือกโฟลเดอร์แยกรูปแล้วตรวจ” (เลือกครั้งแรกครั้งเดียว) ดูว่าจะสร้างอะไร แล้วกด “สร้าง … โฟลเดอร์” — ตั้งแต่วันที่ 16 เลือกรอบได้ (รอบนี้ / รอบ 1–15 / ทั้ง 2 รอบ) และเลือก “หนังที่ขึ้นจอถึงวันที่” ได้ (3.10)
- **ใส่วันที่ถ่ายจากโฟลเดอร์แยกรูป** (3.12): กด “ตรวจวันที่ถ่ายจากโฟลเดอร์แยกรูป” ระบบใส่วันที่ถ่ายจากไฟล์รูปลงช่องหลังชื่อหนังที่ยังว่าง (ช่องที่มีเลขแล้วไม่แตะ) และบอกเรื่องที่น่าจะลืมหรือใส่ผิด แล้วดาวน์โหลด หรือบันทึกทับในโฟลเดอร์ใบเช็ค (ไฟล์เดิมเก็บไว้ใน สำรองก่อนใส่วันที่ถ่าย) • ใส่ให้ใบที่เพิ่งเติม → ผลในขั้นที่ 4 (ไฟล์และ zip) เป็นฉบับที่ใส่แล้วด้วย
- **ตรวจโฟลเดอร์เทียบจอ** (3.8): กด “เลือกโฟลเดอร์เทียบจอแล้วตรวจ” เลือกโฟลเดอร์ที่มีโฟลเดอร์รอบ (เช่น 10 Oct 16-31) ระบบบอกเป็นข้อ ๆ ว่าต้องแก้ในใบเช็ค หรือต้องแก้ในโฟลเดอร์

- **ใบเปล่าเดือนใหม่** (4.8): ขึ้นเดือนใหม่ — เลือกใบเช็คเดือนล่าสุดของทุกคนในกล่อง “ใบเช็คที่ใช้” (เช่น “เปิดใบเช็คทั้งโฟลเดอร์” โฟลเดอร์ 10 OCT 26 / 16-30) แล้วกด **“ทำใบเปล่าจากใบเช็ค”** ระบบทำสำเนาใหม่ทุกไฟล์ (ชื่อไฟล์เดิม) ในทุกชีตจอ ล้างตั้งแต่แถบวันที่แถวแรกลงไป — รายชื่อหนัง แถบวันที่ “ออกวันที่” วันที่ถ่าย สีแถบ / ไฮไลต์ / ช่องจำนวนครั้ง — เก็บหัวตาราง จอ รหัส Format สถานที่ สูตร สีพื้นของชีต แถว #BANGKOK JAM / #… MTP ที่ทีมใส่ไว้ทุกเดือน และชีต Analysis ไว้เหมือนเดิม • **แถบวันที่แรกใส่วันที่ 1 ของเดือนใหม่ให้** (5.5.2 เช่น 1/11/2026 สูตรต่อกันข้ามจอแบบเดิม ชีต BKJ / Metro อยู่ใต้แถว #BANGKOK JAM / #Traffic MTP) และเส้นตารางทุกแถวเท่ากัน แล้วกด **“บันทึกลงโฟลเดอร์ใหม่”** (เลือกโฟลเดอร์ว่างของเดือนใหม่ เช่น 11 NOV 26 / 1-15 — ระบบไม่ยอมบันทึกลงโฟลเดอร์ใบเช็คเดิม) หรือดาวน์โหลด .zip • จอของแต่ละคนเป็นไปตามใบเช็คเดือนล่าสุด (ใบที่ทีมแก้มาทั้งเดือน) • ไฟล์เดิมไม่ถูกแก้
- **ตรวจจอกับฐานข้อมูล** (4.8): ใส่ไฟล์ฐานข้อมูลจอ (Excel ที่มีชีต Data Base: Code / Location / New package / Format / รายชื่อคนรับผิดชอบ) ครั้งเดียว ระบบจำไว้ในเครื่อง (เปลี่ยนไฟล์ / ลบได้) แล้วเทียบกับใบเช็คในกล่อง “ใบเช็คที่ใช้” ว่าใบของใคร **ขาดจอ** (จอนั้นจะไม่ถูกเติม) หรือ **มีจอที่ฐานข้อมูลบอกว่าเป็นของคนอื่น** • จับคู่จากชื่อไฟล์ (คุณปัน.xlsm = ปัน) ตรวจเฉพาะจอที่มีรหัส DGT / ID (Bangkok Jams / Metro / Signature Max และไฟล์ MRT / CCTV / จอห้างไม่ได้ตรวจ) • **ตอนเติมใบเช็ค ขั้นที่ 3 เตือนเรื่องเดียวกัน** และในรายงานการเติมมีบรรทัด “ฐานข้อมูลจอ” (นับเป็นควรตรวจ) • ดูอย่างเดียว ไม่แก้ใบเช็ค
- **เพิ่มจอที่ขาดลงใบเปล่า** (4.8.1): ถ้าใส่ฐานข้อมูลจอไว้ หลังกด “ทำใบเปล่าจากใบเช็ค” ระบบบอกว่าใบเปล่าของใครยังขาดจอ แล้วกด **“เพิ่มจอที่ขาดลงใบเปล่า”** ระบบเพิ่มจอต่อท้ายชีตแพคตามฐานข้อมูล (หรือแพคใน Playlist ที่ใส่ไว้) ใช้หัวตารางแบบเดียวกับจอสุดท้ายในชีต แล้วใส่รหัส Format และสถานที่ของจอใหม่ — คำอธิบายสีด้านข้าง / จอที่ไม่มีรหัสต่อท้าย เลื่อนไปทางขวาให้เอง • เปิดโฟลเดอร์ใบเปล่าที่บันทึกไว้แล้วในกล่อง “ใบเช็คที่ใช้” ก็กดเพิ่มได้ที่การ์ด “ตรวจจอกับฐานข้อมูล” แล้วบันทึกลงโฟลเดอร์ใบเช็ค (ไฟล์เดิมเก็บไว้ในโฟลเดอร์ สำรองก่อนเพิ่มจอ) • เพิ่มให้เฉพาะใบเปล่าแบบบล็อกจอ 3 คอลัมน์ (รหัสจอแถว 10 หรือ 11 — ใบเปล่าแบบเก่าของทีมก็ได้ตั้งแต่ 5.5.5) • จอที่อยู่ในใบของคนอื่น ใช้ “ย้ายจอตามฐานข้อมูล” (5.4)
- **ย้ายจอตามฐานข้อมูล** (5.4): ถ้าฐานข้อมูลจอบอกว่าจออยู่กับอีกคน (สลับจอกัน) ระบบแสดงรายการ “ย้ายจาก … ไปใบของ …” ให้ดูก่อน แล้วกด **“ย้ายจอตามฐานข้อมูล”** ระบบเอาจอออกจากชีตในใบเดิม (จอที่เหลือเลื่อนมาชิดกัน) และเพิ่มในชีตแพคเดียวกันในใบของคนใหม่ (ตั้งแต่ 5.5.6 ใส่ตามลำดับเลขจอ แบบใบเช็คจริงของทีม — แถว Analysis ก็เรียงตามเลขจอในกลุ่มแพค) ใส่รหัส Format และสถานที่ให้ • ย้ายเฉพาะจอที่ทั้งเอาออกและใส่ได้ ถ้าไม่ได้ข้างใดข้างหนึ่งจะไม่แตะไฟล์ทั้งคู่ • อยู่ในการ์ด “ใบเปล่าเดือนใหม่” (หลังกด “ทำใบเปล่าจากใบเช็ค”) และการ์ด “ตรวจจอกับฐานข้อมูล” (เปิดโฟลเดอร์ใบเปล่าไว้ บันทึกแล้วไฟล์เดิมเก็บไว้ในโฟลเดอร์ สำรองก่อนย้ายจอ) • ใบเปล่าเท่านั้น (แบบบล็อกจอ 3 คอลัมน์ รหัสจอแถว 10 หรือ 11 — ใบเปล่าแบบเก่าที่ทีมทำเองก็ได้ตั้งแต่ 5.5.5) • จอสุดท้ายของชีตย้ายได้ (5.5.3) ชีตที่ไม่เหลือจอซ่อนไว้ให้ • ชีต Analysis แก้แถวให้ (เอาแถวจอที่ย้ายออก เพิ่มแถวจอที่ย้ายเข้าในกลุ่มแพคเดียวกัน แก้ช่วง TOTAL) • **ใบของคนใหม่ไม่ต้องอยู่ในชุดเดียวกัน** (5.5.4): เปิดใบของตัวเองใบเดียวก็ย้ายได้ — ระบบเอาจอที่ฐานข้อมูลบอกว่าเป็นของคนอื่นออกจากใบนี้ แล้วใบของคนนั้นได้จอตอนกด “เพิ่มจอที่ขาด” • ถ้าชีตจะไม่เหลือจอ แต่ใบนี้ยังขาดจอแพคเดียวกัน ระบบเพิ่มจอที่ขาดลงชีตนั้นในรอบเดียวกัน ชีตจึงไม่ว่าง

ตัวช่วย: **“ระบบทำงานอย่างไร”** (ภาพรวมสำหรับคนที่ยังไม่รู้จักระบบ) และ **“แนะนำการใช้”** (ทัวร์ชี้ทีละจุด) อยู่ใต้เมนูด้านซ้าย • **“วิธีใช้”** เป็นแท็บด้านบน (ขั้นตอน กฎ และความหมายของ “ควรตรวจ”) • มุมขวาบน: ปุ่มหน้ายิ้มเปิด / ปิดผู้ช่วย “น้องโฟกัส” • สลับโหมดสว่าง / มืด

**หน้าตา (5.0):** โหมดมืดพื้นดำ แสงเรืองม่วง-ฟ้า เป็นค่าเริ่มต้น สลับเป็นโหมดสว่าง (พื้นขาว โทนพาสเทล) ได้ ระบบจำไว้ในเครื่อง • **“น้องโฟกัส”** ผู้ช่วยตัวการ์ตูน (ตั้งแต่ 4.6 ใช้ภาพตัวละครใหม่ 11 ท่า) อยู่ในหน้าหลัก (ท่าเปลี่ยนตามสถานะ) อยู่ในกล่องลากไฟล์ตอนยังว่าง อยู่ในกล่องรอระหว่างทำงาน และโผล่มุมขวาล่างบอกผลตอนรับไฟล์ ตอนเสร็จ และตอนมีเรื่องต้องดู แล้วหายเอง • เครื่องที่ตั้งค่าลดการเคลื่อนไหว ตัวการ์ตูนไม่ขยับ

- **งาน Freeze Screen** (4.1.2): หนังที่ Playlist ใส่จำนวนครั้ง = 0 และหมายเหตุ/ชื่อมีคำว่า Freeze (ขึ้นจอเฉพาะช่วงเวลา) ปกติไม่ใส่ ขั้นที่ 3 มีรายการ “งาน Freeze Screen” ของ Playlist วันนี้ ติ๊กเรื่องที่จะให้ใส่ ระบบจำไว้ใช้วันต่อไป เรื่องที่ติ๊กลงใบเช็คเหมือนหนังทั่วไป (ใต้แถบวันเริ่ม) • หนังจำนวนครั้ง = 0 ที่ไม่ใช่ Freeze ยังไม่ใส่เหมือนเดิม • Signature Max / Show DC ยังใช้หมายเหตุ “ไม่ออน / เฉพาะ / ยกเว้น” ตามเดิม
- **จัดจอเข้าชีตตามแพค** (4.1, สวิตช์ในขั้นที่ 3 — แนะนำ: เปิด): ก่อนเติม ระบบเทียบรหัสจอในชีตจอแยก (40/80 Blue/Red, CITY, Spare) กับ Playlist วันนี้ จอที่ย้ายแพค (เช่น อยู่ชีต Spare แต่ Playlist บอกว่า 40 RED) ระบบย้ายทั้งบล็อกจอ (3 คอลัมน์) ไปชีตของแพคนั้น หนัง วันที่ถ่าย และ “ออกวันที่” ไปด้วยครบ แล้วจัดแถวให้ตรงกับแถบวันที่ของชีตใหม่ตอนเติม • ไม่มีชีตของแพคนั้น = สร้างชีตใหม่จากหน้าตาของชีตเดิม (เช่น “CITY TV 25”) • เรียงจอในชีตตามเลขจอ • แก้ป้ายแพค (แถว 10) ที่เขียนไม่ตรงกับชีต • แก้สูตรในชีต Analysis ให้ชี้ตำแหน่งใหม่ • ย้ายเฉพาะเมื่อใส่ Playlist ของแพคเดิมแล้ว และจอไม่อยู่ในแพคเดิมแต่อยู่ในแพคใหม่แพคเดียว (ไม่แน่ใจ = ไม่ย้าย ขึ้นใน “ไม่ได้ย้าย”) • ใช้ได้เมื่อเปิด “จัดรูปแบบตามใบเช็คจริง” และเลือกสื่อ “ทั้งหมด” • ปุ่มในใบเช็ค (คัดลอกชื่อหนัง / สร้างโฟลเดอร์) ของจอที่ย้ายไม่ย้ายตาม เพราะปุ่มผูกกับโค้ดของชีตเดิม • ผลการเติมมีกล่อง “จัดจอเข้าชีตตามแพค” บอกว่าย้ายอะไรไปไหน และอยู่ใน รายงาน.txt

- **5.5.28 (9 พ.ย. 2569)** — **4 เรื่องที่ค้าง** • (1) **วันที่ใน Playlist ผิด**: แถวที่วันเริ่มออนแอร์อยู่หลังวันสิ้นสุด (เช่น เริ่ม 30/11 สิ้นสุด 1/11) เดิมระบบถือว่ายังไม่ถึงวันเริ่ม หนังเลยหายไปอยู่ใน “แจ้งให้ทราบ” • ตอนนี้ใช้วันที่ในชื่อหนัง (…_30Oct26_…) ถ้าไม่เกินวันสิ้นสุด แล้วบอกใน “ต้องแก้” ทุกครั้ง ให้แจ้งทีม Playlist • (2) **ย้ายจอ Bangkok Jams / Metro LED กลางเดือน**: ใบที่เติมแล้ว ระบบย้ายคอลัมน์ของจอพร้อมวันที่ถ่ายทุกช่องไปใบของคนใหม่ (ลงแถวหนังเรื่องเดียวกัน แถบวันที่เดียวกัน หนังที่ใบใหม่ยังไม่มีต่อท้ายตาราง แล้วจัดแถวตอนเติม) • ชีต Bangkok Jams 2 R กับ A ถือเป็นกลุ่มเดียวกัน • (3) **สร้างใบเปล่าให้คนใหม่**: การ์ดตรวจจอกับฐานข้อมูล มีปุ่ม “สร้างใบเปล่าให้คุณ…” สำหรับคนในฐานข้อมูลที่ยังไม่มีใบเช็ค ใช้ใบเปล่าของคนอื่นที่มีชีตแพคตรงที่สุดเป็นแบบ ใส่จอของคนนั้น (จอที่อยู่ในใบของคนอื่นในชุด ย้ายมา) เอาจอของใบแบบออก ชีตที่ไม่มีจอซ่อนไว้ • (4) **ใบแบบเก่า (เช่น ใบคุณแนน)**: ชีตที่หัวตารางสูงกว่าแบบมาตรฐาน 1 แถว (แถว % อยู่แถว 8) เดิมระบบข้ามตอนเติม • ตอนนี้แทรกแถวว่างบนสุดให้ก่อนเติม สูตรและชีต Analysis เลื่อนตาม • ทดสอบ: ใบเปล่า 28 ไฟล์ + ฐานข้อมูลจริง เหมือนเดิมทุกไฟล์ ยกเว้นหนังที่วันที่ผิดและใบคุณแนน (ทำให้ไม่ได้ลดจาก 9 เหลือ 1) • ใบ 10 Oct และ 11 Nov ที่เติมแล้ว เหมือนเดิมทุกช่อง • ย้ายจอ BKJ1 / BKJ2 / Metro ในใบ 11 Nov วันที่ถ่ายครบทุกช่อง จอและหนังอื่นไม่เปลี่ยน
- **5.5.27 (9 พ.ย. 2569)** — **ชื่อโฟลเดอร์จอ Bangkok Jams ตามกลุ่มในใบเช็ค** • เดิมระบบต่อท้าย (A) / (B) จากชื่อชีตได้แค่ 2 แบบ ชีตใหม่ “BangkokJams2R / BANGKOK_JAM2_R” เลยไม่มีวงเล็บต่อท้าย และรอบใหม่ลอกชื่อ (A) จากรอบก่อน • ตอนนี้อ่านป้ายแถว 10 ของบล็อก (เช่น “BANGKOK JAM2_R”) ก่อน แล้วค่อยดูชื่อชีต ได้ตัวอักษรอะไรก็ได้ เช่น BKJ2_20 @ แยกเกษมราษฎร์ (R) • ใช้ทั้งดาวน์โหลด .zip และสร้างลงโฟลเดอร์ • โฟลเดอร์ของรอบนี้ที่มีอยู่แล้วใช้ชื่อเดิม ไม่เปลี่ยนชื่อ • ทดสอบกับใบเช็ค 11 Nov 1-15 ได้ชื่อตรงกับโฟลเดอร์จริงทั้ง 7 จอ และใบ 10 Oct 16-30 ได้เหมือนเดิมทุกโฟลเดอร์
- **5.5.26 (6 พ.ย. 2569)** — **โยน Playlist หลายวันได้ แม้ใส่แต่ไฟล์ที่ไม่ได้ส่งทุกวัน (เช่น Digital MRT)** • เดิมวันที่เติมดูจากไฟล์ที่ส่งทุกวัน (สรุปรายการหนังแยกจอ / ห้าง / Rama9 / Air Traveller) ไฟล์ที่ไม่ได้ส่งทุกวัน (Digital MRT, Gateway X, The 20, LA PlanB และห้างบางแบบ) ไม่นับ — ถ้าใส่แต่ไฟล์พวกนี้หลายวัน ระบบเติมแค่วันล่าสุด • ตอนนี้ถ้าไม่มีไฟล์ที่ส่งทุกวันเลย วันที่ของไฟล์พวกนี้เป็นวันที่เติม (เช่น MRT 3, 4, 6 พ.ย. → เติม 3 วัน ทีละวัน วันที่ขาดขึ้นเตือนเหมือนเดิม) • ใส่พร้อมไฟล์ที่ส่งทุกวัน ทำแบบเดิม • ทดสอบ: ใบ MRT 4 ไฟล์ + Playlist MRT 6, 7, 8 พ.ย. พร้อมกัน — เติมต่อกัน 3 วัน ผลเหมือนเติมทีละวันทุกช่อง (5.5.25 เติมแค่วันที่ 8) • ชุด Playlist 1–4 พ.ย. ครบทุกแบบ + ไฟล์เพิ่มเติม: แบ่งวันเหมือนเดิม
- **5.5.25 (4 พ.ย. 2569)** — **สร้างโฟลเดอร์แยกรูป: แถว # ของ Bangkok Jams / Metro LED มาด้วย** • แถว # ที่อยู่เหนือแถบวันที่แรก (เช่น #BANGKOK JAM_ATIS_D / _ETA / _NEWS, #EDA, #ETA MTP, #PLACE MTP, #Traffic MTP) เดิมระบบไม่อ่าน เลยไม่มีโฟลเดอร์ ตอนนี้นับเป็นรายการประจำของจอ สร้างโฟลเดอร์ให้ทุกรอบ (1–15 และ 16–สิ้นเดือน) และใส่วันที่ถ่ายได้ • ชีต Bangkok Jams / Metro LED ที่แถว 10 เขียนเลขจอแบบ BKJ1_04 / METRO_05 (เดิมอ่านได้เฉพาะเลขล้วน เช่น 04) ระบบหาจอเจอแล้ว — ใช้ทั้งสร้างโฟลเดอร์ (ลงโฟลเดอร์และ .zip) และใส่วันที่ถ่าย • ใบเปล่าที่มีแค่แถว # ยังนับเป็นใบเปล่า • ทดสอบ: ใบคุณตูนเดือน พ.ย. ได้โฟลเดอร์ # ของ Bangkok Jams ครบ • ใบที่เลขจอเป็น BKJ1_04 / METRO_05 ได้โฟลเดอร์จอ Bangkok Jams 4 จอ + Metro 1 จอ (เดิมไม่มีเลย) • แผนสร้างโฟลเดอร์ชุดทดสอบเดิม: เพิ่มเฉพาะโฟลเดอร์ # ไม่มีโฟลเดอร์ไหนหาย • ผลการเติมเหมือนเดิมทุกช่อง
- **5.5.24 (4 พ.ย. 2569)** — **ย้ายจอกลางเดือนให้เอง (ใบที่เติมแล้ว ย้ายทั้งก้อน)** • สวิตช์ "ย้ายจอตามฐานข้อมูลให้เอง" ใช้กับใบที่เติมแล้วด้วย: จอที่ฐานข้อมูลบอกว่าเปลี่ยนคน ระบบเอาออกจากใบเดิม แล้วใส่ในชีตแพคเดียวกันของใบคนใหม่ พร้อมหนังทุกเรื่องตามแถบวันที่เดิม "ออกวันที่" และวันที่ถ่าย จากนั้นเติมวันนี้ต่อในใบคนใหม่ • แถว Analysis ย้ายตาม • ใบเปล่ายังทำแบบเดิม (ย้าย + เพิ่มจอที่ขาด) • ยังไม่ทำ: จอ Bangkok Jams / Metro LED ในใบที่เติมแล้ว และสร้างใบให้คนใหม่ (บอกไว้ในกล่องผล ให้ทำเอง) • ทดสอบ: ใบเดือน ต.ค. ที่เติมถึง 26 + ฐานข้อมูลทดสอบ (2 จอเปลี่ยนคน) เติมวันที่ 27 — จอ 2 จอย้ายครบ หนังเดิม 156 และ 120 แถวอยู่ใต้แถบวันที่เดิมทุกแถว วันที่ถ่ายตรงทุกช่อง แล้วเติมหนังวันที่ 27 ต่อ • จออื่นในชีตเดียวกันเหมือนเดิมทุกจอ • ใบที่ไม่เกี่ยวเหมือนเดิมทุกช่อง • ใบเปล่า 30 ไฟล์: ผลเหมือน 5.5.21

- **5.5.22 (4 พ.ย. 2569)** — **หน้างานโฟลเดอร์และรูปเรียงตามความถี่ที่ใช้** • แบ่ง 3 กลุ่ม: ทุกวัน (สร้างโฟลเดอร์แยกรูป • ใส่วันที่ถ่าย) → ต้นเดือน (ใบเปล่าเดือนใหม่ • ตรวจจอกับฐานข้อมูล) → ตรวจเป็นครั้งคราว (ตรวจโฟลเดอร์เทียบจอ) • มีหัวข้อกลุ่มทั้งในการ์ด เมนูซ้าย และหน้าที่ยังไม่ได้เลือกใบเช็ค • การทำงานของแต่ละเครื่องมือเหมือนเดิม
- **5.5.21 (4 พ.ย. 2569)** — **ย้ายจอตามฐานข้อมูลให้เองตอนเติม (ขั้นแรก: ใบเปล่า)** • สวิตช์ใหม่ในขั้นที่ 4 "ย้ายจอตามฐานข้อมูลให้เอง" (ค่าเริ่มต้น เปิด ระบบจำไว้ในเครื่อง) • ก่อนเติม ถ้าใส่ฐานข้อมูลจอไว้ ระบบเทียบใบเช็คในชุดที่เติม จออยู่ผิดคน → ย้ายไปใบของคนที่ถูก จอที่ยังไม่มีในใบของใคร → เพิ่มให้ ไม่ต้องกดปุ่มย้าย / เพิ่มเองแล้ว • ย้ายเฉพาะจอที่ทั้งเอาออกและใส่ได้ ถ้าใบของคนใหม่ไม่อยู่ในชุดหรือเติมแล้ว ไม่เอาออก (จอไม่หาย) • ผลการเติมมีกล่อง "ย้ายจอตามฐานข้อมูลให้แล้ว" และอยู่ใน รายงาน.txt พร้อมรายการที่ทำให้ไม่ได้และเหตุผล • ตอนนี้ทำเฉพาะใบเปล่า (ยังไม่มีแถบวันที่) — ใบที่เติมแล้ว (ย้ายกลางเดือนทั้งก้อน) และสร้างใบให้คนใหม่ อยู่ระหว่างทำ • ทดสอบ: ใบเปล่า 30 ไฟล์ + ฐานข้อมูลจอ — ย้าย 20 จอ เพิ่ม 3 จอ ได้ไฟล์เหมือนกดปุ่ม "ย้าย / เอาจอออก" + "เพิ่มจอที่ขาด" ทุกช่อง • เติมวันที่ 1 พ.ย. พร้อมฐานข้อมูล: ย้าย 20 + เพิ่ม 6 จอ แล้วเติมจอที่ย้ายมาครบ ใบที่ไม่เกี่ยวเหมือน 5.5.20 ทุกช่อง • ใบที่เติมแล้ว (ต.ค.) + ฐานข้อมูล: ไม่ย้าย ผลเหมือนเดิมทุกช่อง • ไม่ใส่ฐานข้อมูล: ผลเหมือน 5.5.20

- **5.5.9 (3 พ.ย. 2569)** — **คำอธิบายเข้าใจง่าย + สร้างชีตที่ใบเช็คไม่มีให้** • การ์ดตรวจจอกับฐานข้อมูล: อธิบายสั้น ๆ ว่าทำไมต้องเพิ่ม / ย้าย / เอาจอออก (ตารางถ่ายงานบอกว่าเดือนนี้ใครดูแลจอไหน) • แต่ละบรรทัดมีป้าย ขาด / เป็นของคนอื่นแล้ว / ไม่มีในตาราง และบอกเหตุผล เช่น “ตารางให้คุณโทนแล้ว” “ไม่ได้เปิดใบคุณโจ้ จึงเอาออกจากใบนี้ได้อย่างเดียว” • ปุ่มเลือกบอกชัด: เพิ่มเข้าใบนี้ / ไม่เพิ่ม • ย้ายไปใบคุณ… / เก็บไว้ในใบนี้ • เอาออกจากใบนี้ / เก็บไว้ • **ใบเช็คไม่มีชีตของแพคที่ต้องใส่จอ (เช่น ไม่มีชีต Bangkok Jams 1 หรือ The City 25) — ระบบสร้างชีตให้** โดยคัดลอกชีตแบบเดียวกันในใบเดียวกัน (Bangkok Jams 2 → Bangkok Jams 1 • PBTV แพคอื่น → PBTV 40 Red / The City 25) ตั้งชื่อตามแบบชื่อชีตในใบนั้น ป้ายแพคเป็นชื่อใหม่ แล้วใส่จอ + แถว Analysis • ชีตใหม่ไม่มีปุ่ม Add / Send (ปุ่มผูกกับมาโครของชีตเดิม) • ถ้ามีชีตชื่อนั้นอยู่แล้วแต่ระบบอ่านจอในชีตไม่ได้ ระบบไม่สร้างซ้ำ บอกให้ใส่เอง • ทดสอบ: ใบเปล่า 30 ไฟล์ — สร้างชีต Bangkok Jams 1 ในใบคุณเบนซ์ / PBTV 40 Red และ The City 25 ในใบคุณแนน แล้วย้ายจอเข้าได้ เติม Playlist 1 พ.ย. ลงชีตใหม่ได้ เปิดด้วยโปรแกรมตารางคำนวณอื่นได้ • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.8
- **5.5.8 (3 พ.ย. 2569)** — **เลือกได้ทีละจอ: เพิ่ม / ไม่เพิ่ม • ย้าย / เก็บไว้ • เอาออก / เก็บไว้** • การ์ดตรวจจอกับฐานข้อมูล: ทุกบรรทัดในรายการ “ไฟล์ที่ต้องดู” มีปุ่มเลือก — จอที่ขาด = เพิ่ม (ค่าเริ่มต้น) หรือไม่เพิ่ม • จอที่อยู่ผิดคน = ย้าย / เอาออก (ค่าเริ่มต้น) หรือเก็บไว้ • **จอที่ไม่มีในฐานข้อมูล = เก็บไว้ (ค่าเริ่มต้น) หรือเอาออก** (เอาออกแล้วแถว Analysis เอาออกด้วย ชีตที่ไม่เหลือจอซ่อนไว้) • ปุ่ม “ย้าย / เอาจอออก” และ “เพิ่มจอที่ขาด” ทำตามที่เลือก • แก้: จอ Bangkok Jams ที่ย้ายออกเป็นจอสุดท้ายของชีต แล้วใบนี้ยังขาดจอ Bangkok Jams อีกจอ — ระบบเพิ่มจอที่ขาดลงชีตเดิมในรอบเดียวกัน (เดิมชีตถูกซ่อน แล้วเพิ่มจอที่ขาดไม่ได้ เช่น ใบคุณตูน BKJ1_46 ออก / BKJ1_33 เข้า) • Bangkok Jams 2 ใช้ชีต A / B ตาม New package ในฐานข้อมูล (3 จอที่ไม่ระบุ ระบบใช้ชีตที่มีอยู่ชีตเดียว หรือบอกให้ใส่เอง) • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.7
- **5.5.7 (3 พ.ย. 2569)** — **ตรวจ / ย้าย / เพิ่มจอ Bangkok Jams และ Metro LED ตามฐานข้อมูลได้แล้ว** (เดิมตรวจเฉพาะ DGT / ID) • รหัสในฐานข้อมูล BANGKOKJAM_22 = Bangkok Jams 1 จอ 22 (ในใบเช็คเขียน BKJ1_22 หรือเลข 22) • BANGKOKJAM2_01 = Bangkok Jams 2 จอ 01 (ชีต A / B ตามคอลัมน์ New package) • LEDMETRO_002 = Metro LED จอ 02 • ชีตจอเหล่านี้เป็น 1 คอลัมน์ต่อจอ: เพิ่มจอ = คัดลอกคอลัมน์จอสุดท้ายไปคอลัมน์ถัดไป (สูตรนับ / % ชี้คอลัมน์ใหม่ รหัสและสถานที่ของจอใหม่ หัวตารางขยายตาม เส้นตารางครบ) • เอาจอออก = ลบคอลัมน์ คอลัมน์ทางขวาเลื่อนมา สูตรที่อ้างชีตนี้ทุกชีตเลื่อนตาม ชีตที่ไม่เหลือจอซ่อนไว้ • ชีต Analysis เพิ่ม / เอาแถวให้เหมือนจอ DGT • รองรับทั้งใบแบบเก่า (รหัสแถว 10) ใบแบบมีแถว None (รหัสแถว 11) และใบแบบใหม่ (เลขจอแถว 10) • ชนิดชีตสำคัญกว่าเลขในรหัส (BKJ1_14 ในชีต Bangkok Jams 2 = จอ 2_14) • “.” ที่ใส่กันแถวว่างไม่นับเป็นหนัง • ทดสอบ: ใบเปล่า 30 ไฟล์ + ฐานข้อมูลจอ — ย้ายได้ 16 จอ (Bangkok Jams 4 จอ เช่น BKJ1_32 จากใบคุณโจ้ไปใบคุณโทน) ใบจริง 16–30 ต.ค. และใบเปล่าแบบใหม่ตรวจแล้วตรงกับฐานข้อมูลทุกจอ (ไม่มีเตือนผิด) • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.6
- **5.5.6 (3 พ.ย. 2569)** — **ผลย้ายจอตรงกับใบเช็คจริงของทีม** • เทียบกับใบเช็คจริง 16–30 ต.ค. (ใบที่ย้ายจอครบแล้ว) ของ 4 คน: จอของแต่ละคนครบตรงกันทุกชีต • จอที่ย้ายเข้า / เพิ่มจอที่ขาด ใส่ตามลำดับเลขจอ (แทรกก่อนจอแรกที่เลขมากกว่า จอเดิมไม่เรียงใหม่) แถว Analysis แทรกตามลำดับเดียวกันในกลุ่มแพค — ลำดับในชีตและ Analysis ตรงกับใบจริงทุกคน (เดิมต่อท้าย) • ชีต Analysis ที่ช่วงคะแนนเฉลี่ยขาดแถวจอด้านบน / ล่าง ระบบนับแถวจอที่อยู่ติดกันด้วย แล้วช่วงใหม่ครอบทุกแถว • การ์ดตรวจจอกับฐานข้อมูลบอก “จอที่มีในใบแต่ไม่มีในฐานข้อมูล” (เช่น จอที่เลิกใช้) ให้ดูเอง ระบบไม่ย้าย ไม่เอาออก • ที่ยังต่างจากใบจริง: จอในชีต Spare ที่ทีมย้ายไปชีตแพคตาม Playlist (ฐานข้อมูลบอกแพคไม่ตรงกับที่ใช้จริง) — ตอนเติม ระบบใช้รายการของแพคที่ถูกให้อยู่แล้ว • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.5
- **5.5.5 (3 พ.ย. 2569)** — **ย้าย / เพิ่มจอในใบเปล่าแบบเก่าของทีมได้** • ใบเปล่าที่ทีมทำเอง (ป้ายแพคกับรหัสจออยู่แถว 10 • แบบที่มีแถว None รหัสจอแถว 11 ผลวิเคราะห์แถว 10) ย้ายจอและเพิ่มจอที่ขาดตามฐานข้อมูลได้แล้ว (เดิมขึ้นว่า “ไม่ใช่แบบบล็อกจอ (รหัสจอแถว 11)”) • จอใหม่ใช้หัวตารางของจอสุดท้ายในชีต ใส่รหัส / Format / สถานที่ ตามแถวของแบบนั้น • **ชีต Analysis แบบเก่า** (Pack / Status / Location / Score ไม่มีคำว่า TOTAL แถวสุดท้ายเป็น “คะแนนเฉลี่ย”) แก้แถวให้เหมือนแบบใหม่ สูตร score ชี้แถวผลวิเคราะห์ของชีตนั้น (แถว 9 หรือ 10) • จอที่มีแถวใน Analysis อยู่ก่อนแล้ว (ใส่ไว้ล่วงหน้า) แก้สูตร score ให้ชี้คอลัมน์ที่จออยู่จริง • ใบแบบมีแถว None: ไม่เขียนป้ายแพคทับ “ผลวิเคราะห์ข้อมูลงาน(%)” แถว 10 แล้ว • **การ์ดตรวจจอกับฐานข้อมูล**: ปุ่มย้าย / เพิ่มจอขึ้นเมื่อมีใบเปล่าอย่างน้อย 1 ไฟล์ (เดิมต้องเป็นใบเปล่าทุกไฟล์ — โฟลเดอร์ใบเปล่าที่มีใบ CCTV / จอห้างที่เติมแล้วปนอยู่ ปุ่มไม่ขึ้น) และบอกชื่อใบที่เติมแล้วซึ่งระบบไม่แก้ • ทดสอบ: โฟลเดอร์ใบเปล่าจริงของทีม 30 ไฟล์ + ฐานข้อมูลจอ 01-10-69 ย้ายได้ 12 จอ เพิ่มจอที่ขาด 3 จอ ซ่อนชีตว่าง 2 ชีต Analysis ทุกใบตรงกับจอในชีต แล้วเติม Playlist 1 พ.ย. จอที่ย้ายเติมในใบของคนใหม่ จำนวนหนังเท่าเดิม ไม่มีเรื่องต้องแก้เพิ่ม • จอที่ใบของคนใหม่ไม่มีชีตแพคนั้น / ฐานข้อมูลไม่ระบุแพค ยังต้องทำเอง (ระบบบอกเหตุผล) • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.4
- **5.5.4 (3 พ.ย. 2569)** — **ย้ายจอได้โดยไม่ต้องมีใบของคนอื่น** • ย้ายจอตามฐานข้อมูล: เปิดแค่ใบของตัวเอง (กับฐานข้อมูลจอ) ก็ย้ายได้ จอที่ฐานข้อมูลบอกว่าเป็นของคนอื่น ระบบเอาออกจากใบนี้ (จอที่เหลือเลื่อนมาชิดกัน แถว Analysis เอาออก ชีตที่ไม่เหลือจอซ่อนไว้) แล้วใบของคนนั้นได้จอตอนเขากด “เพิ่มจอที่ขาด” ในใบของเขา • รายการก่อนกดบอกว่า “เอาออกจาก … — ฐานข้อมูลบอกว่าเป็นของ …” • จอที่อยู่ซ้ำ 2 ใบ (ใบของเจ้าของตามฐานข้อมูลมีอยู่แล้ว) เอาออกจากใบที่ไม่ใช่เจ้าของ • ถ้าเปิดใบของทั้งสองคนพร้อมกัน ยังย้ายจากใบหนึ่งไปอีกใบแบบเดิม • **ชีตไม่ว่างโดยไม่จำเป็น**: ถ้าจอที่เอาออกเป็นจอสุดท้ายของชีต แต่ใบนี้ยังขาดจอแพคเดียวกัน (เช่น 40 Blue ออก 1 จอ เข้า 1 จอ) ระบบเพิ่มจอที่ขาดลงชีตนั้นในรอบเดียวกันพร้อมแถว Analysis ชีตไม่ต้องซ่อน • ทดสอบ: เปิดใบเปล่าใบเดียวกับฐานข้อมูลทดสอบ เอาออก 2 จอ เพิ่มจอที่ขาดในชีตเดียวกัน 1 จอ ซ่อนชีตว่าง 1 ชีต Analysis ถูกต้อง (คะแนนคำนวณได้) • เปิดครบทุกใบยังย้ายจากใบหนึ่งไปอีกใบได้ 4 จอเหมือน 5.5.3 • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.3
- **5.5.3 (3 พ.ย. 2569)** — **ย้ายจอได้ครบ ไฟล์พร้อมใช้** • ย้ายจอตามฐานข้อมูล: จอที่เป็นจอเดียวของชีต (เช่น จอเดียวของแพค 40 Blue ย้ายไปอยู่กับอีกคน) ย้ายได้แล้ว ชีตที่ไม่เหลือจอซ่อนไว้ให้ (ไม่ลบ เพราะมาโครในไฟล์ผูกกับชีต ลบแล้ว Excel มีส่วนค้าง) ระบบไม่อ่านชีตที่ซ่อนและไม่มีจอ ตอนเติมไม่ขึ้นเตือน • **ชีต Analysis แก้ให้อัตโนมัติ**: ใบเดิมเอาแถวของจอที่ย้ายออก ใบใหม่เพิ่มแถวต่อท้ายกลุ่มแพคเดียวกัน (ใช้ชื่อ / หมายเหตุ / สถานะจากใบเดิม สูตร score ชี้คอลัมน์ของจอ ใส่ตำแหน่งเดิมถ้าแพคนั้นเพิ่งว่าง) และช่วง AVERAGE ของแถว TOTAL ตามแถวใหม่ • “เพิ่มจอที่ขาด” เพิ่มแถว Analysis ให้ด้วย (ชื่อ = รหัส สถานที่ (ป้ายแพค) (Format)) • ผลการย้ายบอกชีตที่ซ่อนและจำนวนแถว Analysis ที่แก้ • ทดสอบ: ฐานข้อมูลทดสอบที่ย้ายจอ 4 จอ (3 จอเป็นจอเดียวของชีต) ย้ายได้ครบ ชีตว่างซ่อน 2 ชีต Analysis ถูกต้องทุกใบ (เปิดด้วยโปรแกรมตารางคำนวณอื่นแล้วคะแนนคำนวณได้) • เติม 1 พ.ย. ลงใบที่ย้ายแล้วไม่มีเรื่องต้องแก้เพิ่ม • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.2
- **5.5.2 (3 พ.ย. 2569)** — **ใบเปล่าเดือนใหม่มีวันที่ 1 ให้เลย** • ตอนกด “ทำใบเปล่าจากใบเช็ค” แถบวันที่แรกของทุกชีตจอใส่วันที่ 1 ของเดือนใหม่ (ดูจากวันที่ล่าสุดในใบเดิม ถึงวันที่ 5 = เดือนเดียวกัน) สูตรต่อกันข้ามจอ (=C21, =F21 …) แบบเดิมของทีมยังอยู่ • การ์ดบอกว่าใส่วันที่อะไรให้ • ชีต BKJ / Metro: เก็บแถบแรกที่อยู่ใต้แถว #BANGKOK JAM / #Traffic MTP ไว้ด้วย ตอนเติมวันที่ 1 จึงได้หน้าตาแบบใบจริง (เดิมระบบย้ายแถบไปไว้เหนือแถวพวกนั้น เรียงแถวใหม่ และไม่ใส่แถบวันถัดไป) • **เส้นตารางใบเปล่าเท่ากันทุกแถว**: แถวที่เคยเป็นแถบวันที่ของเดือนเดิมไม่มีเส้นแบ่งช่องหายเป็นช่วง ๆ แล้ว และช่องที่หายไปในแถวของตารางใส่เส้นให้ครบ • ใบเปล่าที่แถบแรกมีวันที่แล้วยังเพิ่มจอ / ย้ายจอตามฐานข้อมูลได้ (สูตรแถบแรกอ้างจอก่อนหน้าตามลำดับใหม่) • ทดสอบ: เติม 1 พ.ย. ลงใบเปล่าใหม่ ชีต Plan B TV / CITY / Spare / Signature ได้ผลเหมือนใบเปล่าแบบเดิมทุกช่อง • จอที่ย้ายเข้ามาเรียงตามเลขจอตั้งแต่วันที่ 1 (เดิมวันที่ 2) • ย้ายจอตามฐานข้อมูลทดสอบได้ 3 จอเหมือนเดิม • การเติมใบเช็คประจำวันชุดทดสอบเดิมผลเหมือน 5.5.1
- **5.5.1 (2 พ.ย. 2569)** — **ชื่อโฟลเดอร์จอใน .zip เลือกได้ 2 แบบ** • “ตามใบเช็ค” (แบบ 5.5 ค่าเริ่มต้น) หรือ “ตามโฟลเดอร์ที่มีอยู่” (Chrome / Edge) • แบบหลัง: กดดาวน์โหลดแล้วเลือกโฟลเดอร์ Gallary / แยกรูปครั้งแรกครั้งเดียว (ระบบจำไว้ กด “เปลี่ยนโฟลเดอร์” ได้) ระบบอ่านอย่างเดียว ไม่สร้าง ไม่แก้อะไรในโฟลเดอร์นั้น • ใช้ชื่อจอเดิมทุกตัวอักษร (รอบล่าสุดของ Gallary หรือชื่อแบบเดิม) แก้ป้ายแพคเฉพาะจอที่ย้ายแพค • จอที่ยังไม่มีโฟลเดอร์ใช้ชื่อจากใบเช็ค (ขึ้นป้าย “ชื่อจากใบเช็ค”) • จอที่อยู่ในจอปิดถาวรไม่ใส่ • ผลบอกจำนวนจอที่ใช้ชื่อตามโฟลเดอร์ / ชื่อจากใบเช็ค • ทดสอบกับรายชื่อโฟลเดอร์จริง: ชื่อจอ 84 จอตรงกับโฟลเดอร์เดิมทั้งหมด (10 จอที่แบบตามใบเช็คต่างไป เช่น Format / เว้นวรรค ได้ชื่อเดิม) • แบบตามใบเช็คได้ไฟล์เหมือน 5.5 ทุกโฟลเดอร์ • การเติมใบเช็คผลเหมือน 5.5

- **5.4 (2 พ.ย. 2569)** — **ย้ายจอตามฐานข้อมูล** • จอที่ฐานข้อมูลบอกว่าอยู่กับอีกคน ระบบย้ายลงใบของคนใหม่ให้ได้แล้ว (ใบเปล่าเท่านั้น) • แสดงรายการก่อนกด (จอ ใบเดิม/ชีต → ใบใหม่/ชีต) และจอที่ย้ายไม่ได้พร้อมเหตุผล • เอาจอออกจากชีตเดิมแล้วจอที่เหลือเลื่อนมาชิดกัน สูตรนับเลื่อนตาม • เพิ่มต่อท้ายชีตแพคตามฐานข้อมูลในใบของคนใหม่ (ไม่มีชีตแพคนั้น ใช้แพคเดียวกับใบเดิม) • ย้ายเฉพาะจอที่ทั้งเอาออกและใส่ได้ • ไม่เอาจอสุดท้ายของชีตออก • มีในการ์ด “ใบเปล่าเดือนใหม่” และการ์ด “ตรวจจอกับฐานข้อมูล” (บันทึกแล้วไฟล์เดิมอยู่ในโฟลเดอร์ สำรองก่อนย้ายจอ • ดาวน์โหลดเป็น ใบเช็ค_ย้ายจอ.zip) • ทดสอบ: ฐานข้อมูลทดสอบที่สลับจอ 4 จอ ย้ายได้ 3 จอ (อีกจอเป็นจอเดียวในชีต ระบบข้ามพร้อมบอกเหตุผล) แล้วเติม Playlist 1 พ.ย. ลงใบที่ย้ายแล้ว จอที่ย้ายเติมในใบของคนใหม่ ไม่มีเรื่องต้องแก้ • ใบเปล่าแบบเก่าที่ไม่ใช่บล็อกจอ ระบบไม่แตะไฟล์และบอกเหตุผล • การเติมใบเช็คชุดทดสอบเดิมผลเหมือน 5.3.3

- **3.12 (21 ต.ค. 2569)** — **ใส่วันที่ถ่ายจากโฟลเดอร์แยกรูป** (ขั้นที่ 3, ไม่ต้องใส่ Playlist): ใส่ใบเช็ค → กล่อง “ใส่วันที่ถ่ายจากโฟลเดอร์แยกรูป” → “ตรวจวันที่ถ่ายจากโฟลเดอร์แยกรูป” • ระบบดูรูปในโฟลเดอร์ของแต่ละจอ (เดือน → รอบ → ชื่อหนัง; หนังใต้แถบ 1–15 ดูโฟลเดอร์ 1-15, ใต้แถบ 16 ขึ้นไปดู 16-30 / 16-31) อ่านวันที่ถ่ายจากข้อมูลในไฟล์รูป (ใช้วันที่ล่าสุดที่อยู่ในรอบและไม่ก่อนวันที่หนังขึ้น) แล้วใส่เลขวันที่ในช่องหลังชื่อหนัง**เฉพาะช่องที่ยังว่าง** ช่องที่มีเลขหรือสูตรอยู่แล้วไม่แตะ ตัวเลขใหม่ใช้สีเดียวกับช่องที่มีวันที่ถ่ายแล้วในคอลัมน์นั้น (เช่น ช่องดำตัวขาว) • BKJ / Metro LED ใส่แยกตามเลขจอที่หัวคอลัมน์ • บอกจุดที่น่าจะผิด: มีเลขแต่ไม่พบรูป / เลขไม่ตรงกับวันที่ในรูป (ไม่แก้ให้) / มีรูปแต่ใส่วันที่ให้ไม่ได้ (ไม่มีวันที่ถ่ายในไฟล์ เช่น ส่งต่อทาง LINE, วันที่ในรูปไม่อยู่ในรอบ) — **เลือกวันที่ถ่ายเองได้ทีละจอ** / ยังไม่มีรูป / หาโฟลเดอร์จอไม่เจอ • ดูก่อนใส่ แล้วดาวน์โหลด (.zip พร้อมรายงาน) หรือบันทึกทับไฟล์เดิม (ไฟล์ก่อนใส่เก็บใน สำรองก่อนใส่วันที่ถ่าย) • ทดสอบ: ใบเช็คของทีม 6 ไฟล์ + รูปทดสอบ — ใส่ถูกทุกกรณี เปลี่ยนเฉพาะช่องที่บอกไว้ (8 จาก 8) มาโครอยู่ครบ • ผลการเติมใบเช็คเหมือน 3.11.1 ทุกไฟล์ (เทียบเนื้อในไฟล์ 838 ส่วน) และแผนสร้างโฟลเดอร์แยกรูปเหมือนเดิม
- **3.11.1 (21 ต.ค. 2569)** — กล่องสร้างโฟลเดอร์แยกรูป: **ช่องวันที่อ่านเข้าใจง่ายขึ้น** • ชื่อช่องเป็น “หนังที่ขึ้นจอถึงวันที่” ตัวเลือกแรก “ทุกเรื่องในรอบ (ค่าปกติ)” • รายการวันที่มีเฉพาะวันที่มีหนังขึ้น และบอกจำนวน เช่น “18 ต.ค. • ขึ้น 7 เรื่อง” (วันแรกของรอบ = “ต้นรอบ … เรื่อง”) • ใต้ช่องมีคำอธิบาย: ค่าปกติสร้างทุกเรื่อง / ถ้าเลือกวันที่ บอกว่าหนังที่ขึ้นหลังวันนั้นกี่เรื่องจะยังไม่สร้าง พร้อมตัวอย่างชื่อ • ผลการสร้างและผลการเติมใบเช็คไม่เปลี่ยน
- **3.11 (21 ต.ค. 2569)** — **สร้างโฟลเดอร์แยกรูปได้โดยไม่ต้องใส่ Playlist**: ขั้นที่ 3 ใส่ใบเช็คที่เติมแล้ว → กล่อง “สร้างโฟลเดอร์แยกรูปจากใบเช็คนี้” ใต้รายการใบเช็ค → กด “อ่านรายชื่อหนังจากใบเช็ค” → เลือกรอบ / วันที่ได้เหมือนขั้นที่ 4 → ตรวจ → สร้าง • ระบบอ่านรายชื่อหนังกับแถบวันที่จากใบเช็คอย่างเดียว ไม่แก้ใบเช็ค ใช้วันที่ล่าสุดที่มีหนังในใบเช็คเป็นวันทำงาน (เช่น ใบเช็คเติมถึง 20 ต.ค. = รอบ 16–31 ต.ค.) • นับเฉพาะหนังของเดือนนั้น (ใบเช็คที่ยังมีของเดือนก่อนไม่ปน) • ทดสอบ: ใบเช็คของทีม 6 ไฟล์ที่เติมวันที่ 20 ต.ค. อ่านรายชื่อหนังได้ตรงกับตอนเติมทุกจอ (68 จาก 68 บล็อก) และแผนสร้างโฟลเดอร์ทั้ง 3 แบบ (รอบนี้ / รอบ 1–15 / ทั้ง 2 รอบ) เหมือนการสร้างหลังเติมทุกจอ • แก้เลขเวอร์ชันที่มุมหน้าเว็บ (3.10 ยังขึ้น 3.9.2) • ผลการเติมใบเช็คไม่เปลี่ยน
- **3.10 (21 ต.ค. 2569)** — **สร้างโฟลเดอร์แยกรูป: เลือกรอบ และเลือกวันที่ได้** • ตั้งแต่วันที่ 16 เลือกได้ว่าจะสร้าง **รอบ 16–สิ้นเดือน (รอบนี้, ค่าเริ่มต้น)** / **รอบ 1–15** / **ทั้ง 2 รอบ** — สำหรับจอที่ยังไม่ได้สร้างโฟลเดอร์รอบ 1–15 (รอบ 1–15 = หนังใต้แถบวันที่ 1–15 ของใบเช็ค เหมือนตอนสร้างในช่วงวันที่ 1–15; จอที่ไม่มีหนังรอบ 1–15 ไม่สร้าง) • ช่อง **“เอาหนังที่เริ่มถึงวันที่”** = ทั้งหมดของรอบ (ค่าเริ่มต้น) หรือเลือกวันที่ เช่น 18 ต.ค. แล้วสร้างเฉพาะหนังที่อยู่ใต้แถบวันที่ไม่เกินวันนั้น (เลือกวันก่อน 16 กับ “ทั้ง 2 รอบ” = สร้างแค่รอบ 1–15) • รายการก่อนสร้างบอกรอบของแต่ละจอ • ทดสอบกับสำเนาชื่อโฟลเดอร์แยกรูปจริง (ลบรอบ 1–15 ของ DGT029 / BKJ1_04 / Twin Tube ออก): ค่าเริ่มต้นได้แผนเหมือน 3.9.2 ทุกจอ, รอบ 1–15 สร้าง 837 โฟลเดอร์ใน 51 จอ แล้วตรวจซ้ำเหลือ 0, ทุกวันที่ที่เลือกไม่มีหนังเกินวันที่หรือข้ามรอบ • ผลการเติมใบเช็คไม่เปลี่ยน
- **3.9.2 (21 ต.ค. 2569)** — ตรวจโฟลเดอร์เทียบจอ: **รายการหลักมีเฉพาะจอที่อยู่ในใบเช็คที่เติม** (นับใน “ต้องแก้ N เรื่อง” และ “คัดลอกผลตรวจ”) • จออื่นที่ระบบเจอตอนเทียบโฟลเดอร์ในเครื่อง (เช่น ชื่อใน Plan B TV 240 ไม่ตรง หรือจอเดียวกันมีโฟลเดอร์ 2 แพค) แยกไปไว้ในหัวข้อพับ “จออื่นที่ไม่อยู่ในใบเช็คที่เติม” ไม่นับรวม กดเปิดดูได้
- **3.9.1 (21 ต.ค. 2569)** — ตัวเลือกหนังต่อสัญญาวันที่ 16 เข้าใจง่ายขึ้น: จากช่องติ๊ก “แถวเดิมไม่ใส่ ออก 16” เป็นช่องเลือก “แถวเดิมของหนังต่อสัญญาวันที่ 16” = **เขียน “ออก 16” (ปกติ)** / **ไม่ต้องเขียน** พร้อมคำอธิบายสั้นใต้ช่อง (หนังที่ต่อสัญญา ระบบลงแถวใหม่ใต้แถบ 16 ให้อยู่แล้ว ช่องนี้คือแถวเดิมของเรื่องนั้น) • ค่าที่เคยติ๊กไว้ยังใช้ได้เหมือนเดิม ผลการเติมไม่เปลี่ยน
- **3.9 (20 ต.ค. 2569)** — **เลือกสีช่องว่างเหนือแถบวันที่ได้** (แถบสีฟ้าอ่อนในช่องว่างใต้รายการของจอที่หนังน้อยกว่า ก่อนถึงแถบวันที่ถัดไป): ตั้งค่ากลางในขั้นที่ 3 ใต้ “สีแถบวันที่” — ตามชีต / ฟ้าอ่อน / เหลืองอ่อน / เขียวอ่อน / ชมพูอ่อน / ส้มอ่อน / เทาอ่อน / เลือกเอง — และเลือกแยกรายไฟล์ได้ที่ช่อง “สีช่องว่างเหนือแถบวันที่” ใต้ชื่อไฟล์ (ระบบจำไว้ตามชื่อไฟล์) • สีที่เลือกเปลี่ยนช่องว่างทุกแถบในชีตให้เป็นสีเดียวกัน • “ตามชีต” (ค่าเริ่มต้น) = ใช้สีที่ชีตใช้อยู่ ชีตที่เคยใช้สีที่เลือกไว้ ระบบอ่านสีนั้นต่อ ไม่เปลี่ยนกลับเป็นฟ้า • ใบที่ไม่ได้เลือกสี ผลการเติมเหมือน 3.8.3 ทุกไบต์
- **3.8.3 (20 ต.ค. 2569)** — ชื่อจอใน Plan B TV 240: ไฮไลต์ส่วนที่ต่างกันระหว่างชื่อใน 240 กับชื่อในโฟลเดอร์แพค (เช่น **(40B)** / **(80B)** ของ DGT258, **(80R) (CLF)** ที่ชื่อใน 240 ของ DGT217 ไม่มี) จะได้เห็นทันทีว่าชื่อไหนผิดตรงไหน • ผลการเติมใบเช็คไม่เปลี่ยน
- **3.8.2 (20 ต.ค. 2569)** — **Plan B TV 240 ตรวจแค่ชื่อจอ**: โฟลเดอร์ 240 เป็นโฟลเดอร์รวมไว้ดูรายชื่อจอ ระบบจึงไม่ตัดสินแพคหรือป้าย (40B) (80R) จากโฟลเดอร์นี้แล้ว แต่เทียบชื่อโฟลเดอร์จอใน 240 กับชื่อในโฟลเดอร์แพค แล้วขึ้นในกลุ่มใหม่ “ชื่อจอใน Plan B TV 240” พร้อมทั้งสองชื่อให้ดูเทียบกัน (เช่น DGT258 … (40B) ใน 240 / … (80B) ใน Plan B TV 80 BLUE) รวมถึงชื่อที่ไม่มีในโฟลเดอร์แพค และชื่อที่ยังไม่มีใน 240 • ตารางจำนวน แถว 240 ไม่นับจอในใบเช็ค • ผลการเติมใบเช็คเหมือน 3.8.1 ทุกไบต์
