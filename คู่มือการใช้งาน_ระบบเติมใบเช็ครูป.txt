1. ระบบนี้ทำอะไร
======================================================================

แปลง Playlist รายวัน เป็นใบเช็ครูป (.xlsm) ของผู้ตรวจแต่ละคน
แทนการเปิด Playlist คัดลอกรายชื่อหนังลง Notepad แล้ววางลงใบเช็คทีละจอ

  - อ่าน Playlist ครบ 11 ไฟล์ แล้วเติมใบเช็ครูปทุกไฟล์ในครั้งเดียว
  - เป็นไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง
  - ไฟล์ทั้งหมดประมวลผลในเครื่องของผู้ใช้ ไม่ถูกส่งออกไปที่ใด
  - มาโคร รูปแบบ และสีเดิมในไฟล์ .xlsm อยู่ครบ ใช้ต่อได้ทันที

      "แนะนำการใช้"             ทัวร์ชี้ทีละจุดของหน้าที่เปิดอยู่

      ปุ่มรูปดวงจันทร์/ดวงอาทิตย์  สลับโหมดสว่าง / มืด (ระบบจำไว้ให้)
  - เลขเวอร์ชันอยู่ท้ายหน้า

4. ขั้นตอนประจำวัน (4 ขั้น)
======================================================================

----------------------------------------------------------------------
ขั้นที่ 1  ใส่ Playlist
----------------------------------------------------------------------
 1) ถ้ามีงานของวันก่อนค้างอยู่ กด "ล้าง Playlist (เริ่มวันใหม่)" แล้วกด OK
    (ล้างทั้ง Playlist ใบเช็ครูป และผลการเติมของวันก่อน)
 2) ลากไฟล์ Playlist ทั้ง 11 ไฟล์ ลงกล่อง "ลากไฟล์ Playlist มาวางที่นี่"
    (หรือคลิกที่กล่องเพื่อเลือกไฟล์ เลือกหลายไฟล์พร้อมกันได้)
    ระหว่างอ่านไฟล์จะมีกล่องบอกความคืบหน้า "กำลังอ่าน Playlist 3 จาก 11 ไฟล์"
    ไฟล์ใหญ่ (เช่น Signature Max) อาจใช้เวลาหลายวินาที ไม่ต้องกดซ้ำ
    ถ้าเผลอใส่ใบเช็ครูปในขั้นนี้ ระบบย้ายไปไว้ในขั้นที่ 3 ให้เอง
 3) ดู "เช็กลิสต์ Playlist" ทั้ง 11 ช่อง
      - ช่องสีน้ำเงินมีไฟเขียว   = ใส่แล้ว บอกวันที่ จำนวนจอ และรายการ
      - ช่องเส้นประ            = ยังไม่ได้ใส่ (ใต้เช็กลิสต์บอกว่าขาดแบบไหน)
      - ไฟเหลือง               = วันที่ของไฟล์ไม่ตรงวันทำงาน
      - Show DC "ใช้ฉบับล่าสุดที่มี" = วันนี้ไม่มีฉบับใหม่ ใช้ได้ตามปกติ
    ครบแล้วจะขึ้นแถบสีเขียว "ครบ 11 แบบแล้ว"
 4) ตรวจ "Playlist วันที่" ด้านขวาว่าเป็นวันที่จะทำ และรอบถูกต้อง
    (แถบน้ำเงิน = รอบ 1–15  แถบเขียว = รอบ 16–สิ้นเดือน)
 5) ต้องไม่มีกรอบสีแดง (อ่านไฟล์ไม่ได้) หรือกรอบสีเหลือง (ไฟล์หลายวันปนกัน)
 6) กด "ไปเติมใบเช็ครูป"
    (ถ้าต้องแก้รายการหนังก่อน กด "ตรวจ / แก้ไขก่อน")

 ถ้าเติมเฉพาะใบเช็คของตัวเอง ใส่เฉพาะ Playlist แบบที่ใบเช็คนั้นใช้ก็ได้
 ขั้นที่ 3 จะบอกว่าใบเช็คแต่ละไฟล์ต้องใช้แบบไหน

 หมายเหตุ: ใส่ไฟล์ของจอเดียวกันซ้ำ ระบบจะใช้ไฟล์ใหม่แทนของเดิม

----------------------------------------------------------------------
ขั้นที่ 2  ตรวจ / แก้ไข  (ไม่บังคับ)
----------------------------------------------------------------------
 ถ้า Playlist ถูกต้องแล้ว กด "ไปเติมใบเช็ครูป" ได้เลย
 ถ้าต้องแก้รายการหนังก่อนเติม ดูหัวข้อ 6

----------------------------------------------------------------------
ขั้นที่ 3  เติมใบเช็ครูป
----------------------------------------------------------------------
 1) ลากใบเช็ครูปของวันก่อนหน้าลงกล่อง "ลากไฟล์ใบเช็ครูปมาวางที่นี่"
    ใส่ของทุกคนพร้อมกัน หรือเฉพาะของตัวเองก็ได้
 2) ดูรายการ "ใบเช็ครูปที่ใส่แล้ว" ระบบตรวจให้ว่าแต่ละไฟล์ใช้ Playlist แบบไหน
    และหาจอทุกจอในใบเช็คเจอหรือไม่ (ใช้กติกาเดียวกับตอนเติมจริง)
      - "พร้อมเติม" (สีเขียว)          = มี Playlist ครบทุกจอที่ไฟล์นี้ใช้
      - "ยังขาด Playlist n แบบ" (สีเหลือง) = ป้ายสีเหลืองบอกแบบที่ขาด
      - "หาไม่พบ n จอ" (สีเหลือง)        = มีรหัสจอที่ไม่อยู่ใน Playlist ไหนเลย
        กดเติมได้ แต่จอเหล่านี้จะไม่ถูกเติมและขึ้นใน "ควรตรวจ"
        ถ้าต้องการให้ครบ กลับไปใส่ Playlist ที่ขาดในขั้นที่ 1 ก่อน
      - "ใช้รายการแทน ..."             = จอที่ระบบจะเติมจากรายการของสื่ออื่น
        (เช่น จอ CITY ที่อยู่ในชีต Spare) จะขึ้นใน "ควรตรวจ" ให้ตรวจ
      - "จะไม่ถูกเติม" (สีแดง)          = ไฟล์เสีย ไม่ใช่ไฟล์ Excel หรือเป็นไฟล์
        Playlist ที่ใส่ผิดขั้น ไฟล์อื่นยังเติมได้ตามปกติ
    (กดปุ่ม x ข้างชื่อไฟล์ เพื่อเอาไฟล์ที่ใส่ผิดออก ใส่ไฟล์ชื่อซ้ำ = แทนที่ของเดิม)
 3) ตรวจ "วันที่ทำงาน (วันของ Playlist)" และรอบที่ขึ้นใต้ช่อง
      - รอบ 1–15            แถบวันที่สีน้ำเงิน
      - รอบ 16–สิ้นเดือน     แถบวันที่สีเขียว ต่อท้ายรอบ 1–15 ในชีตเดิม
    ถ้าวันที่ไม่ถูก พิมพ์ใหม่ในช่อง (ดูหัวข้อ 5)
 4) สวิตช์ "จัดแบบที่ทำด้วยมือ" ต้องเปิดอยู่ (สีส้ม) — เป็นค่าเริ่มต้น
 5) กด "เติมใบเช็ครูป N ไฟล์" จะมีกล่องบอกความคืบหน้า รอจนขึ้นหน้า "ผลการเติม"
    (ระหว่างเติม หน้าจอจะล็อกไว้ กดซ้ำหรือเอาไฟล์ออกไม่ได้ เพื่อกันผลผิด)

----------------------------------------------------------------------
ขั้นที่ 4  ผลการเติม
----------------------------------------------------------------------
 1) ดูแถบสรุป "เติมเสร็จ __ ไฟล์  __ จอ  __ ควรตรวจ"
 2) ไฟล์ที่มีป้ายสีเหลือง "ควรตรวจ" กดปุ่มลูกศรท้ายแถวเพื่อดูรายละเอียด
    (ความหมายของแต่ละข้อความ ดูหัวข้อ 8)
 3) กดปุ่มสีส้ม "ดาวน์โหลดทั้งหมด (.zip)" ในแถบสรุป ได้ไฟล์ ใบเช็ครูป_เติมแล้ว.zip
      - ข้างในมีใบเช็ครูปทุกไฟล์ที่เติมได้ (ชื่อเดิม) และไฟล์ รายงาน.txt
      - ไฟล์ที่ขึ้น "ไม่ได้เติม" (สีแดง) จะไม่อยู่ใน zip ดูเหตุผลในรายการของไฟล์นั้น
      - ดาวน์โหลดทีละไฟล์ได้จากปุ่มลูกศรลงข้างชื่อไฟล์
 4) แตกไฟล์ zip แล้วเปิดใบเช็คใน Excel ตรวจก่อนใช้งาน
 5) เก็บใบเช็คของวันนี้ไว้ เป็นไฟล์ตั้งต้นของวันพรุ่งนี้

 สำคัญ: ไฟล์ที่เติมแล้วจะยังไม่ถูกบันทึกลงเครื่องจนกว่าจะกดดาวน์โหลด
       ถ้ากดปิดหน้าก่อนดาวน์โหลด เบราว์เซอร์จะถามยืนยันก่อน

5. การตั้งค่าในขั้นที่ 3
======================================================================

วันที่ทำงาน (วันของ Playlist)
  - เว้นว่างไว้ = ใช้วันที่จากชื่อไฟล์ Playlist (ขึ้นบอกใต้ช่อง)
  - ถ้าต้องการกำหนดเอง พิมพ์แบบใดแบบหนึ่ง เช่น
        9-Oct-26     2026-10-09     9/10/2026     9/10/2569
        9/10/69      9 ต.ค. 69      (ปี 2 หลัก = ปี พ.ศ. เช่น 69 = 2569)
    ระบบจะแปลงเป็นแบบ 9-Oct-26 และบอกวันที่ที่อ่านได้ใต้ช่อง
  - ถ้าพิมพ์วันที่ที่ไม่มีจริงหรืออ่านไม่ได้ (เช่น 31-Feb-26) ช่องจะเป็นสีแดง
    ปุ่มเติมจะกดไม่ได้จนกว่าจะแก้ หรือลบออกเพื่อใช้วันที่จาก Playlist
  - ใต้ช่องบอกรอบที่จะใช้ และเตือนถ้าเป็นวันที่ 1 (ยังไม่ใส่ "ออกวันที่")
  - Show DC เป็นไฟล์ของรอบถัดไปได้ (เช่น "On 8-10-26" ที่ส่งมาวันที่ 7)
    ระบบจึงไม่ใช้วันที่ของ Show DC กำหนดวันทำงาน

จัดแบบที่ทำด้วยมือ  (เปิดไว้เสมอ)
  หนัง # ขึ้นก่อน (ไฮไลต์เหลือง) → เรียง A–Z → แยกตามวันเริ่ม
  → ใส่ "ออกวันที่"  ตามแบบที่ทีมทำมือ

ตัวเลือกเพิ่มเติม  (ปกติไม่ต้องแก้)
  - สื่อ              เติมจอแยกเฉพาะสื่อที่เลือก (40/80 Blue/Red, CITY, Spare)
                      ส่วน Signature Max, Show DC, BKJ, Metro LED ยังเติมตามปกติ
  - เรียงลำดับ        ตามไฟล์ Playlist / ก-ฮ A-Z / ขึ้นใหม่ก่อน *
  - เฉพาะหนัง "ขึ้นใหม่"
  - ตัดชื่อซ้ำในจอเดียวกัน  (เปิดอยู่เป็นค่าเริ่มต้น)
  - รวมรายการปลดต่อท้าย   (ใช้ตรวจว่าหนังถอดแล้ว)
  * มีผลเฉพาะเมื่อปิด "จัดแบบที่ทำด้วยมือ"

6. ขั้นที่ 2 ตรวจ / แก้ไข Playlist (ไม่บังคับ)
======================================================================

แก้รายจอ
  - กรองตามสื่อด้วยปุ่มด้านบน หรือพิมพ์ค้นหารหัส/ชื่อจอ เช่น DGT009
  - คลิกการ์ดจอเพื่อเปิดตารางหนังของจอนั้น
  - สวิตช์ "ออนแอร์"  เปิด = ออนแอร์  ปิด = ปลด (ใส่สถานะ "ถอด" ก็ปลดให้)
  - แก้ชื่อหนัง Type สถานะ วินาที จำนวนครั้ง หมดสัญญา หมายเหตุ ได้ในตาราง
  - "+ เพิ่มหนัง" เพิ่มทีละเรื่อง / "วางรายชื่อหลายบรรทัด" เปิดกล่องให้วาง
    รายชื่อที่คัดลอกจาก Excel หรือ Notepad บรรทัดละเรื่อง
  - ลูกศรเลื่อนลำดับ / ถังขยะลบแถว
  - จอที่แก้แล้วมีป้ายสีเขียว "แก้แล้ว"

แก้ทุกจอพร้อมกัน
  - พิมพ์ส่วนหนึ่งของชื่อหนัง แล้วเลือก
      ปลดทุกจอ / คืนเป็นออนแอร์ / ลบทิ้ง / เปลี่ยนชื่อทุกจอที่พบ
  - เพิ่มหนังเรื่องใหม่เข้าทุกจอของสื่อที่เลือกในครั้งเดียว

ปุ่มในขั้นที่ 1 ที่เกี่ยวข้อง
  - "บันทึกโปรเจกต์"   เก็บ Playlist ที่แก้ไว้เป็นไฟล์ playlist_project.json
  - "เปิดโปรเจกต์"     โหลดไฟล์ .json กลับมาทำต่อ
  - "ส่งออก Playlist (.xlsx)"  รวมทุกจอเป็นตารางเดียว ใช้ตรวจหรือส่งต่อ
  ถ้าแก้ไขแล้วจะปิดหน้า ให้บันทึกโปรเจกต์ก่อน (ระบบจะถามยืนยันก่อนปิด)

7. กฎที่ระบบใช้จัดใบเช็ครูป
======================================================================

  1. วันแรกของรอบ (วันที่ 1 และ 16) ลงหนังที่ออนอยู่ทั้งหมด
     หนัง # ขึ้นก่อน (ไฮไลต์เหลือง) แล้วเรียง A–Z
  2. วันถัดไป หนังที่ยังไม่มีในใบเช็คและสถานะ "ขึ้นใหม่"
     ลงใต้แถบวันที่ของวันนั้น  หนังที่มีอยู่แล้วอยู่ที่เดิม ไม่ซ้ำ
  3. "ออกวันที่ N" ใส่เมื่อถึงวันที่หนังออก (วันที่ 1 ยังไม่ใส่)
  4. สถานะ "ขึ้นใหม่ไฟล์เดิม" / "ต่อสัญญา" ใช้แถวเดิม
     ไม่ใส่ออกวันที่ และไม่เพิ่มแถวซ้ำ
  5. ตัวเลขที่ผู้ตรวจนับไว้ ย้ายตามชื่อหนังให้เอง
  6. วันที่ 16 เริ่มรอบใหม่เป็นแถบสีเขียวต่อท้ายในชีตเดิม ไม่แตะรอบ 1–15
  7. แถบท้ายตารางเป็นวันถัดไปเสมอ (ไว้ลงหนังของพรุ่งนี้)
  8. หนังที่ลงไว้แล้วแต่ไม่มีใน Playlist วันนี้ ยังเก็บไว้ในใบเช็ค
  9. หนังที่สัญญาเริ่มหลังวันที่ทำงาน ยังไม่ใส่ (ไม่ลงล่วงหน้า)
 10. Signature Max / Show DC ทำตามหมายเหตุ "ไม่ออน …" และ "ออนเฉพาะ …"
 11. จอแยก ถ้าจำนวนครั้ง = 0 ไม่ใส่
 12. Metro LED ใช้ชีตของวันล่าสุดในไฟล์

8. อ่านผล "ควรตรวจ"
======================================================================

ข้อความ                                      ทำอย่างไร
----------------------------------------------------------------------
"ไม่พบจอนี้ใน Playlist"
    ยังไม่ได้ใส่ Playlist ของสื่อนั้น หรือรหัสจอในใบเช็คไม่ตรง
    → ใส่ Playlist ให้ครบ แล้วเติมใหม่

"ใช้รายการของสื่อ ... เพราะสื่อ ... ไม่มีจอนี้ — โปรดตรวจ"
"ไม่มีจอนี้ใน Playlist CITY — ใช้รายการ THE CITY แทน"
    ระบบเติมจากรายการใกล้เคียงให้ → เทียบกับ Playlist ว่าถูกต้อง

"รหัสนี้อยู่ในหลายสื่อ ... ตั้งชื่อชีตให้มี 40/80 + Blue/Red, CITY หรือ Spare"
    ชื่อชีตในใบเช็คไม่บอกสื่อ → แก้ชื่อชีต แล้วเติมใหม่

"ข้าม (ไม่พบรหัสจอ ...)"
    ชีตนั้นไม่มีรหัสจอ DGT/ID ในแถว 10-11 จึงไม่ได้เติม
    ถ้าเป็นชีตสรุปหรือชีตที่ไม่ใช้ ไม่ต้องทำอะไร

"ตรวจ: มีตัวเลขที่นับไว้ N ช่องของหนังที่ไม่อยู่ในรายการแล้ว ..."
    ตัวเลขนับของหนังที่หายไปจากรายการ ไม่ได้ย้ายมา → ตรวจในใบเช็คเดิม

"ตรวจ: ไม่ใส่ตามหมายเหตุ "ไม่ออน/ออนเฉพาะ" → ..."
"ตรวจ: ไม่ใส่เพราะจำนวนครั้ง = 0 → ..."
    บอกรายชื่อหนังที่ตั้งใจไม่ใส่ → ดูว่าตรงกับ Playlist

"ตรวจ: ชีตนี้มีรอบ 16–สิ้นเดือน (แถบเขียว) แล้ว แต่วันที่ทำงานอยู่ในรอบ 1–15"
    วันที่ทำงานน่าจะผิด → แก้วันที่ทำงานในขั้นที่ 3 แล้วเติมใหม่

"ไม่พบจอ Base ใน Playlist"
    → ใส่ Playlist ที่มีจอ Base ก่อน แล้วเติมใหม่

"สรุปการจัดแต่ละชีต" (ข้อความด้านล่าง)
    เป็นข้อมูล ไม่ใช่ข้อผิดพลาด เช่น รอบที่ใช้ จำนวนหนังใหม่ของวันนี้
    จำนวนตัวเลขนับที่ย้าย

9. ปัญหาที่พบบ่อยและวิธีแก้
======================================================================

ถาม  ขึ้นกรอบสีแดง "อ่านไม่ได้ n ไฟล์"
ตอบ  - "ไม่รู้จักรูปแบบไฟล์" → ตรวจว่าเป็นไฟล์ Playlist .xlsx ที่ถูกต้อง
       (ไม่ใช่ PDF หรือไฟล์อื่นที่แนบมาในอีเมลเดียวกัน)
     - "อ่านได้แต่ไม่พบรายการหนัง" → รูปแบบไฟล์อาจเปลี่ยน
       ระบบใช้ข้อมูลเดิมไว้ก่อน ให้แจ้งผู้ดูแลระบบ

ถาม  ขึ้นกรอบสีเหลือง "ไฟล์ Playlist มีหลายวันปนกัน"
ตอบ  กด "ล้าง Playlist (เริ่มวันใหม่)" แล้วใส่เฉพาะไฟล์ของวันนั้น
     (ถ้าไม่ล้าง ระบบจะใช้วันล่าสุด)
     Show DC ฉบับก่อนหน้าไม่ทำให้ขึ้นกรอบนี้ เพราะเป็นเรื่องปกติ

ถาม  วันที่ Playlist ไม่ถูก / ขึ้น "ไม่พบวันที่ Playlist"
ตอบ  พิมพ์วันที่ในช่อง "วันที่ทำงาน" ขั้นที่ 3 เช่น 9-Oct-26

ถาม  ปุ่ม "เติมใบเช็ครูป" กดไม่ได้
ตอบ  ยังไม่ได้ใส่ใบเช็ครูป ยังไม่ได้ใส่ Playlist หรือวันที่ทำงานที่พิมพ์ไว้ผิด
     ข้อความใต้ปุ่มจะบอกว่าขาดอะไร

ถาม  ในหน้าผลการเติม มีไฟล์ขึ้น "ไม่ได้เติม" สีแดง
ตอบ  ไฟล์นั้นเสีย ไม่ใช่ไฟล์ Excel หรือเป็นไฟล์ Playlist ที่ใส่ผิดขั้น
     ไฟล์อื่นเติมตามปกติ ใส่ไฟล์ที่ถูกต้องแล้วเติมใหม่

ถาม  ใช้คีย์บอร์ดอย่างเดียวได้ไหม
ตอบ  ได้ กด Tab ไปที่กล่องใส่ไฟล์ แล้วกด Enter เพื่อเลือกไฟล์
     ในหน้าต่างและทัวร์ กด Tab เลื่อนปุ่ม กด Esc เพื่อปิด

ถาม  ใบเช็คขึ้น "ยังขาด Playlist n แบบ"
ตอบ  ดูป้ายสีเหลืองว่าขาดแบบไหน แล้วกลับไปใส่ไฟล์นั้นในขั้นที่ 1
     ถ้าวันนี้ไม่มีไฟล์แบบนั้นจริง กดเติมได้เลย จอนั้นจะขึ้นใน "ควรตรวจ"

ถาม  เผลอปิดหน้าก่อนดาวน์โหลด
ตอบ  เปิดระบบใหม่ ใส่ Playlist และใบเช็คของวันก่อนหน้าชุดเดิม แล้วเติมใหม่
     จะได้ผลเหมือนเดิม

ถาม  วันนี้ไม่มี Show DC ฉบับใหม่
ตอบ  Show DC ไม่ได้ส่งทุกวัน ใส่ฉบับล่าสุดที่มี ช่อง Show DC ในเช็กลิสต์
     จะขึ้น "ใช้ฉบับล่าสุดที่มี" ใช้ได้ตามปกติ

ถาม  อยากดูทัวร์แนะนำอีกครั้ง / อยากเปลี่ยนเป็นโหมดมืด
ตอบ  กด "แนะนำการใช้" มุมขวาบน (ทัวร์ของหน้าที่เปิดอยู่)
     ปุ่มรูปดวงจันทร์ / ดวงอาทิตย์ มุมขวาบน สลับโหมดสว่าง / มืด

ถาม  Excel ขึ้นแถบเหลือง Protected View / Security Warning เรื่องมาโคร
ตอบ  เป็นปกติของไฟล์ .xlsm ที่ดาวน์โหลดมา กด Enable Editing / Enable Content

ถาม  ผลในใบเช็คไม่ตรงกับที่ควรเป็น
ตอบ  เก็บไฟล์เหล่านี้ส่งผู้ดูแลระบบ
       1) Playlist ของวันนั้นทุกไฟล์
       2) ใบเช็คก่อนเติม (ของวันก่อนหน้า)
       3) ใบเช็คหลังเติม และไฟล์ รายงาน.txt จากไฟล์ zip
     และบอกว่าจอไหน / หนังเรื่องไหน ไม่ตรง

10. รวบรวม Playlist อัตโนมัติด้วย n8n (ถ้าเปิดใช้)
======================================================================

ระบบเสริมบน n8n Cloud ช่วยรวบรวมไฟล์ Playlist จากอีเมลให้
  - ทุกชั่วโมง 7:00–18:00 ตรวจ Gmail ของบัญชีที่รับ Playlist
  - เก็บไฟล์ของวันนั้นลงโฟลเดอร์ Google Drive ที่ตั้งชื่อตามวันที่
  - ส่งอีเมลสรุป หัวเรื่อง "Playlist <วันที่>: x/10 แบบ"
    บอกว่าได้ครบหรือยัง ขาดแบบไหน พร้อมลิงก์โฟลเดอร์
  - Show DC ถ้ายังไม่มีฉบับใหม่ ใช้ฉบับล่าสุด (ค้นย้อนหลัง 14 วัน)
  - Metro LED มาทาง LINE จึงไม่นับใน 10 แบบ ต้องดาวน์โหลดจาก LINE เอง

ใช้ร่วมกับระบบเติมใบเช็ครูป
  1) รออีเมลขึ้น "ครบแล้ว" (10/10 แบบ)
  2) เปิดลิงก์โฟลเดอร์ในอีเมล → ดาวน์โหลดทั้งโฟลเดอร์ → แตกไฟล์ zip
  3) ดาวน์โหลด Metro LED จาก LINE
  4) ลากทั้ง 11 ไฟล์ลงขั้นที่ 1 แล้วทำตามหัวข้อ 4 ต่อ
  ถ้าอีเมลเตือนว่ามีหลายไฟล์ของแบบเดียวกัน ให้ตรวจว่าฉบับไหนถูก
  แล้วใส่เฉพาะฉบับนั้น

วิธีติดตั้งและตั้งค่า: ดูไฟล์ n8n/README.md ใน GitHub
